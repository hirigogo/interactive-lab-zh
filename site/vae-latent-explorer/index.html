VAE 潜空间探索器

VAE 中的 β 旋钮在重建质量与潜空间结构之间进行权衡。当 β=0 时，你得到的是一个普通自编码器 —— 重建效果好，但潜空间杂乱无章。当 β=10 时，你得到的是一个强 VAE —— 潜空间是干净的单位高斯分布，但样本会变得模糊。拖动滑块即可亲眼看到这一点。

约 8 分钟深度学习 · VAE · 生成模型

VAE 的损失包含两项：重建项（我能把这东西解码回多少？）与一个把潜分布 q(z|x) 拉向标准正态先验的 KL 散度。β-VAE（Higgins 2017）只是对 KL 项加权：L = recon + β · KL。拖动 β 以观察其作用。

发生了什么： 当 β=0 时，潜变量点聚成几个紧密的团块 —— 每个类别一团。当 β=1 时，这些团块变成宽度为 1 的斑块，大致铺满一个单位圆。当 β=10 时，一切都坍缩到原点（后验坍缩）—— 模型不再使用潜变量。

权衡法则。 β=1 即原始 VAE。Higgins 2017 发现 β≈4 能产生「解耦」的潜变量，即每个维度控制一个因子。β>6 通常会坍缩。务必查看样本，而不只是潜变量分布图。

重参数化技巧

z = μ(x) + σ(x) ⊙ ε    ε ~ N(0, I)

编码器（对每个输入）输出 μ 与 σ。我们从一个固定的噪声分布中采样 ε，并确定性地计算 z。噪声全部落在没有参数的 ε 中，因此梯度可以顺畅地流过 μ 与 σ。正是这个技巧使 VAE 的训练得以奏效。

ELBO

log p(x) ≥ E_{q(z|x)}[log p(x|z)]  −  KL(q(z|x) ∥ p(z))　（ELBO 不等式）

ELBO 是对数边缘似然的一个下界。我们无法直接计算 log p(x)（边缘分布难以处理），但我们可以计算并最大化它的下界。这正是 VAE 训练所做的事。

ELBO 的逐步推导

我们想要 $\log p(x)$，但它难以处理。引入一个近似后验 $q_\phi(z\mid x)$（即编码器），并利用对任意 $q$ 都成立的事实：

log p(x) = E_{q_φ(z|x)} [ log p(x, z) − log q_φ(z|x) ] + KL( q_φ(z|x) ∥ p(z|x) )　（分解式）

右端的 KL 项 $\ge 0$，因此把它丢弃就得到一个下界 —— 即 ELBO。整理可得：

ELBO(x) = E_{q_φ(z|x)} [ log p_θ(x|z) ] − KL( q_φ(z|x) ∥ p(z) )　（两项之和）

两项各有直观含义：第一项要求 $z$ 能够重建 $x$（即解码器损失）；第二项要求 $z$ 的后验匹配先验。最大化 ELBO 即在二者之间权衡。

重参数化技巧 · VAE 为何能训练

从 $z \sim \mathcal{N}(\mu_\phi(x), \sigma_\phi^2(x))$ 中采样，对 $\mu_\phi, \sigma_\phi$ 而言并没有梯度。于是重参数化：

z = μ_φ(x) + σ_φ(x) ⊙ ε,    ε ~ N(0, I)

现在采样步骤只是一个逐元素的乘加运算；$\mu_\phi, \sigma_\phi$ 因而能够接收到梯度。Kingma & Welling 2014 —— 正是这个技巧使 VAE 得以端到端训练。

后验坍缩 · 及三种补救办法

一种常见的失效：对于每一个 $x$，编码器都输出 $q_\phi(z\mid x) \approx p(z)$，而解码器学会了忽略 $z$。KL 项为零；重建质量平平却很稳定；潜变量毫无用处。症状：KL 很低、样本模糊、样本不依赖于 $z$。

  • β-VAE。 用 $\beta < 1$ 对 KL 项加权（若追求解耦则用 $\beta > 1$，Higgins 等，2017）。KL 预热是更简单的实用修正。
  • Free bits。 仅当每个潜变量维度的 KL 超过某一阈值时才施加 KL 项（Kingma 等，2016）。可防止那些本来可能携带信息的维度坍缩。
  • 更强的解码器族。 使用 PixelCNN / 自回归解码器，让潜变量有处可去、有所作为。或者采用更强的先验（VQ-VAE 2017、Vamp-prior）。

2026 年的 VAE 家族

  • VQ-VAE。通过向量量化码本得到离散潜变量。标准的图像分词器；为大多数离散词元的图像 / 音频模型提供动力。
  • NVAE / VDM。在较小规模上可与扩散模型质量相当的层次化 VAE。
  • 潜空间扩散 VAE。Stable Diffusion 内部那个微小的 VAE（KL-f8）：像素 → $1/8$ 分辨率下的 4 通道潜变量。训练一次，随即冻结。
  • 条件 VAE。用于类别条件生成的 $q_\phi(z\mid x, c)$；或用于带结构化上下文的表格 / 时间序列数据。
