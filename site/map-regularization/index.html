交互式讲解

MAP = 似然 × 先验

“在损失上加一个正则项”听起来像是个取巧的窍门，其实不然。为你的参数设置一个先验，将其与似然相乘，再最大化该乘积 — 这就是 MAP 估计，而正则项会自然而然地显现出来。本页将这三个分布统统画在参数空间中，让你看清 MAP 如何坐落于数据的答案（MLE）与先验向零的拉力之间。

约 11 分钟 深度学习 · 正则化 · 贝叶斯推断
前言

两个峰，一个乘积

取一个仅含两个权重的微小模型 $\theta = (\theta_1, \theta_2)$。似然 $p(\text{data}\mid\theta)$ 是一个以最佳拟合数据的取值（即 MLE）为中心的隆起。先验 $p(\theta)$ 则是以原点为中心的隆起，编码了“令权重保持较小”这一信念。Bayes 将其相乘得到后验：

$$\underbrace{p(\theta\mid\text{data})}_{\text{posterior}} \;\propto\; \underbrace{p(\text{data}\mid\theta)}_{\text{likelihood}}\; \underbrace{p(\theta)}_{\text{prior}}.$$

对两边取 $-\log$，乘积便化为求和 — 一个数据拟合项加上一个惩罚项：

$$\hat\theta_{\text{MAP}} = \arg\min_\theta\; \underbrace{-\log p(\text{data}\mid\theta)}_{\text{loss}} \;+\; \underbrace{-\log p(\theta)}_{\text{regularizer}}.$$

高斯先验给出 $-\log p(\theta) \propto \lVert\theta\rVert_2^2$ — 这就是ℓ₂ 正则化（岭回归）。拉普拉斯先验给出 $-\log p(\theta) \propto \lVert\theta\rVert_1$ — 这就是ℓ₁ 正则化（lasso）。原来正则项自始至终就是一个先验。

实验

参数空间，实时呈现

方形区域即参数空间。蓝色等值线为似然（数据拟合），青色等值线为先验（以原点为中心），橙色等值线则为二者的乘积，即后验。三个被标记的点分别是 MLE（数据的最佳拟合）、MAP（后验峰值）与原点。移动控件，观察 MAP 如何在数据与零之间被来回拉扯。

三件值得一试的事。 （1）在高斯先验下将先验宽度 $\tau$ 向左拖（更窄、更强的先验）：MAP 会平滑地滑向原点 — ℓ₂ 会把一切都略微收缩。 （2）切换到拉普拉斯先验 并收窄 $\tau$：MAP 会骤然跳到某一坐标轴上，把 $\theta_2$ 推向恰好 为零 — 菱形的那一角正是 ℓ₁ 的稀疏性。 （3）将数据量 向右推（或降低噪声）：蓝色的似然变得更紧，MAP 便向 MLE 回移 — 数据足够多时，先验便不再重要。
收益

为何 ℓ₁ 产生稀疏而 ℓ₂ 不会

观察先验的等值线。高斯 先验画出的是光滑的椭圆 — 处处圆润。当似然椭圆压向它时，二者在一个两个坐标皆非零的一般位置点相交：ℓ₂ 会把权重向零收缩，但极少收缩到恰好为零。

拉普拉斯 先验画出的则是菱形 — 其尖锐的角恰好落在各坐标轴上。一个倾斜的似然椭圆极有可能最先在某个角处触到菱形，而角上有一个坐标等于零。这一几何事实 — 尖的 ℓ₁ 球与圆的 ℓ₂ 球之别 — 正是 lasso 产生稀疏模型而岭回归不会的全部原因。

要点。 正则化强度即先验宽度：窄先验（$\tau\!\downarrow$、$\lambda$ 大）表示强烈相信权重接近零；宽先验（$\tau\!\uparrow$、$\lambda$ 小）几乎不构成约束。而似然的掌控力随数据增多而收紧，故当 $N\to\infty$ 时 $\hat\theta_{\text{MAP}}\to\hat\theta_{\text{MLE}}$。频率学派的带正则回归与贝叶斯 MAP 估计，不过是同一计算从两侧观察的结果。
