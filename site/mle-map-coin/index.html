交互式讲解

抛硬币上的 MLE 与 MAP

频率派与贝叶斯派争论了一个世纪。在单枚硬币上，两种估计都只是一个可以算出来的数字。滑动先验，抛几次硬币，观察估计如何从 MLE（只用数据）滑向 MAP（数据 + 先验）。

约 10 分钟 概率 · 贝叶斯推断
第 1 步

设定

一枚硬币有未知偏置 $p$。你抛掷 $N$ 次，观察到 $h$ 次正面、$t = N - h$ 次反面。似然为 $\mathcal{L}(p) = p^h (1-p)^t$。MLE 在 $\hat p_{\text{MLE}} = h/N$ 处取峰。

对 $p$ 施加 $\text{Beta}(\alpha, \beta)$ 先验。后验为 $\text{Beta}(\alpha + h,\ \beta + t)$ —— 仍在同一分布族中，只需把计数加上去。MAP 在该 Beta 分布的众数处取峰。

试一试

交互组件

此处放置 $\alpha$、$\beta$、真实 $p$ 与 $N$ 的交互滑块。

绘图：在同一坐标轴上展示似然、先验与后验。

读数：MLE、后验均值、MAP、KL(后验 ‖ 先验)。

状态：框架已搭好，实现待补。

第 2 步

该观察什么

  • $N$ 小 · 先验胜出。 后验靠近先验。MAP $\neq$ MLE。
  • $N$ 大 · 数据胜出。 后验在 $h/N$ 附近收缩。MAP $\to$ MLE。
  • 先验错误 · 修正缓慢。 即便真实偏置为 0.8，一个很强的 Beta(50, 50) 先验仍会把 MAP 拉向 0.5。
