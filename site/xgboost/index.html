XGBoost 额外做了什么

朴素的梯度提升让 $f_t$ 拟合 负梯度 $-\partial L / \partial \hat y$（一阶近似）。XGBoost（Chen & Guestrin，2016）则进行 二阶泰勒展开，并让树去优化 牛顿步 方向。其分裂增益与叶值公式为：

其中 $g_i = \partial L / \partial \hat y_i$，$h_i = \partial^2 L / \partial \hat y_i^2$。对于平方损失 $L = \frac{1}{2}(y - \hat y)^2$，这退化为朴素的 GBM（$g = \hat y - y$，$h = 1$）。对于逻辑损失，XGBoost 顾及 Hessian 的更新收敛速度明显更快。

第 3 步

你应当看到的现象

  • 第一棵树只是一个阶梯函数。 深度为 3 意味着至多 8 个叶节点；预测是对真实函数的块状近似。
  • 其后每一棵树都修正残差。 观察残差面板：它变得更具噪声也更小，除非你持续添加树，否则永远无法真正达到零。
  • 较低的 η = 更平滑的拟合。 在 η=0.05 加 100 棵树时曲线平滑。在 η=0.5 加 20 棵树时则参差不齐。总的「步长」相同，偏差/方差的权衡不同。
  • 提升法与随机森林对比。 随机森林对许多 相互独立 的深树取平均；提升法则构建 相互依赖 的浅树。随机森林稳健且可并行；提升法更准确但需串行。自 2018 年以来，在表格任务上 XGBoost / LightGBM / CatBoost 在大多数基准中胜过随机森林。
第 4 步

生产环境中的 XGBoost —— 真正该调什么

  • n_estimators / num_boost_round。 配合验证集使用早停。500–5000 是有用的范围；更多则是浪费。
  • learning_rate (η)。 大数据集用 0.01–0.1，小数据集用 0.05–0.3。树更多时取更低值。
  • max_depth。 3–10。对于交互丰富的大型表格数据可更深；对于噪声数据则更浅。
  • min_child_weight。 相当于按 Hessian 加权的每叶最小样本数。默认值为 1；对噪声数据可调高。
  • subsample / colsample_bytree。 每棵树的行 / 特征自助采样。0.7–0.9 是最佳区间 —— 引入随机性，起到正则化作用。
  • reg_alpha / reg_lambda。 作用于叶权重的 L1 / L2 正则。若你的特征很多且担心过拟合，可加以调校。
  • tree_method。 一切情况都使用 'hist'（现代 XGBoost 的默认值）；它比 'exact' 更快且同样准确。
  • objective。 'reg:squarederror'、'binary:logistic'、'multi:softprob'、'rank:pairwise'、'reg:tweedie'（零膨胀计数），……
  • 单调性约束。 强制「预测必须对特征 X 单调」—— 在保险、医疗、监管场景中很有用。
  • 缺失值。 XGBoost 会为每个分裂原生地学习 NaN 的最佳方向路由；除非必要，否则不要做插补。
一句口号。 对于类型混杂、含缺失值且行数 $\le$ 数百万的表格数据，XGBoost / LightGBM / CatBoost 依然是最强大 也最简单 的默认选择。神经表格模型（TabNet、FT-Transformer、SAINT）偶尔在基准中获胜；但在大多数生产场景中，梯度提升树仍然胜出。
第 5 步

值得了解的变体

  • LightGBM。 基于直方图；按叶生长（优先最深）的分裂方式；在大数据上比 XGBoost 更快；稍易过拟合，但用 num_leaves 和正则化即可轻松控制。
  • CatBoost。 原生处理类别特征（无泄漏的目标编码）；默认超参数极佳；在大数据上是三者中最慢的。
  • HistGradientBoosting（sklearn）。 纯 Python 的替代方案；比最初的 sklearn GBM 快得多；精度相当；随 sklearn 一同提供。
  • NGBoost。 输出一个 分布（均值 + 方差）的梯度提升；对下游的不确定性工作很有用。
  • XGBoost-Spark / Dask-XGBoost。 面向超大数据集的分布式实现。
  • TabNet、FT-Transformer、SAINT。 神经表格模型的替代方案；有时胜出，常常打平，很少能证明额外的 ML-ops 复杂度是值得的。
