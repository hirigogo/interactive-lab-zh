一步步构建后验分布

拖动一个先验，在坐标轴上点击添加数据点，观察后验如何逐渐成形。随后进入共轭情形，把后验预测分布与 MAP 代入法区分开，在一个非共轭后验上让网格求值、Metropolis MCMC 与变分推断同场竞速，最后以贝叶斯线性回归收尾——其不确定带恰好在数据缺失处向外张开，所有数值都由纯 JS 实时计算。

前言

从“那个正确答案”到答案的分布

最大似然为未知参数 $\theta$ 给出一个数字——即与数据最为相符的那个取值。贝叶斯方案则认为：数据并不挑出单个 $\theta$，而是更新你对所有可能取值的信念。这一信念是一个概率分布；更新它的配方只有一行数学：

三种成分：先验 $p(\theta)$（你此前所持的信念）、似然 $p(\mathcal{D}\mid\theta)$（数据如何依赖于 $\theta$），以及后验 $p(\theta \mid \mathcal{D})$（你更新后的信念）。分母只是一个使后验积分为 1 的归一化常数；我们大多会忽略它。

本文其余全部内容，不过是把一句口号用九种越来越困难的方式呈现出来：

这句口号。 后验 $\propto$ 先验 $\times$ 似然。这就是全部。所有艰难的机器（MCMC、VI、GP、贝叶斯深度学习）都只是在无法写出闭式解时，如何完成这一个乘积而已。

第 2 步

数据以多快的速度锐化后验？

后验精度（方差的倒数）等于先验精度与数据精度之和：

有两个清晰的推论。第一，后验方差按 $1/n$ 下降——这正是经典的“数据锐化信念”，但有了一个有原则的速率。第二，先验贡献了固定数量的伪数据：当 $\sigma=1$ 时，一个 $\sigma_0 = 0.1$ 的紧致先验“相当于” $\sigma^2 / \sigma_0^2 = 100$ 个数据点。

在 $1/\sigma_0$ 处的水平渐近线会随着 $n$ 增大而消失；最终数据精度会压倒你带来的任何先验。

第 4 步

后验预测分布 ≠ 代入式 MAP

后验是关于参数的正确对象。但在下游我们通常关心的是预测新数据。有两种做法：

  • 代入式 MAP / MLE。 挑选一个 $\theta$（最大值处），并预测 $p(x_{\text{new}}\mid\hat\theta)$。
  • 后验预测分布。 对所有 $ heta$ 按后验加权求平均：$\;p(x_{ ext{new}}\mid\mathcal{D}) = \int p(x_{ ext{new}}\mid heta)\,p( heta\mid\mathcal{D})\,d heta$。

代入式更快，但在不确定性上说了谎。只要你尚未精确知道 $\theta$，后验预测分布就会更宽——而这正是校准最为关键的区间。观察随着 $n$ 增大，这一差距如何缩小。

这在实践中会带来什么代价。 一个在类别上输出 softmax 的神经网络就是代入式的：它假装权重是固定的。当权重仍不确定时（在真实数据上，这几乎总是如此），预测分布本应更宽。这一差距表现为一个过度自信、校准失当的模型——这正是贝叶斯深度学习试图修复的缺陷。
第 5 步

如果后验不属于一个漂亮的分布族呢？

共轭先验给了我们闭式的后验。真实的后验——来自神经网络、层次模型或非高斯似然——通常并不共轭。三类算法覆盖了全部实践：

  • 网格求值。 在网格上计算未归一化的后验，再归一化。精确，但在超过约 3 维后失效。
  • MCMC（我们使用 Metropolis-Hastings）。 在 $\theta$ 上的随机游走，其分布收敛到后验。在极限意义下精确，但有限样本下有噪声。
  • 变分推断（VI）。 选择一个易处理的分布族（我们使用高斯分布），通过最小化与真实后验之间的 KL 散度来拟合它。快速但有偏——对多峰目标尤为如此。

第 6½ 步

层次模型——部分池化，贝叶斯的超能力

假设你有若干相互关联的组：许多站点、传感器、学校、患者、批次。每组都有一小堆观测。你可以每组各拟合一个模型（“不池化”），也可以对所有数据拟合一个模型（“完全池化”）。两者都以已知的方式出错。贝叶斯的修正是部分池化：一个层次先验，让每组拥有自己的均值，同时把离群者拉向全局均值。

$\mu$ 是全局均值；$\tau$ 表示各组被拉向它的强度；$\theta_g$ 是组特有的均值。$\theta_g$ 的后验被收缩向 $\mu$，收缩量取决于 $\tau$ 与该组的数据量 $n_g$。

收缩公式。 对于高斯数据，第 $g$ 组的后验均值是一个加权平均：$\hat\theta_g = w_g \bar y_g + (1 - w_g)\,\mu,$ $\;w_g = \frac{n_g/\sigma^2}{n_g/\sigma^2 + 1/\tau^2}.$ $n_g$ 大或 $\tau$ 小 ⇒ 相信该组；$n_g$ 小或 $\tau$ 大 ⇒ 相信全局均值。部分池化逐组地在两个极端之间插值。

为何这很重要：数据匮乏的组从数据丰富的组借用力量，而无需被迫与它们保持一致。James 与 Stein（1961）证明：在均方误差意义下，该估计量优于各组的 MLE——在三维及以上，不池化可被证明是次优的。

第 7 步

人们常搞错的五件事

迷思

“贝叶斯派 = 主观，频率派 = 客观。”
两者都要选取假设：频率派选取一个抽样模型与一套流程（显著性水平、估计量）；贝叶斯派选取一个抽样模型与一个先验。贝叶斯把假设显式化，这才是真正的差别。

迷思

“数据足够多时先验就无所谓了。”
对低维、可良好辨识的参数而言成立（第 2 步已具体展示）。但在高维模型、层次模型，或任何似然在某些方向上平坦的设定中都不成立——而现代深度学习大多如此。

迷思

“MCMC 总会收敛到真相。”
在无限样本的极限下，是的。但在有限链与糟糕的建议分布下（第 5 步），MCMC 会在单个峰中停留很久，返回一个自信却错误的直方图，还告诉你它已收敛。务必运行多条链。

迷思

“VI 只是更快的 MCMC。”
VI 本质上有偏：它返回你变分族中最近的那个成员，即便该族中没有任何成员看起来像真相。在多峰后验上，高斯 VI 拟合可能在第二个峰上给出零质量，却仍声称自己已经“收敛”。

迷思

“贝叶斯神经网络不过是带先验训练的网络。”
先验是容易的部分。困难的部分是在 1 亿维的参数空间上获得一个校准良好的后验，而今天的 MCMC 与 VI 都做不到诚实地完成它。SGLD、Laplace 近似、深度集成与 SWAG 都是实用的折中——它们中没有一个是“贝叶斯答案”。

迷思

“如果你只想要一个点估计，贝叶斯推断是大材小用。”
后验均值对任意损失都能最小化均方误差；MAP 则最小化 0–1 损失。二者常常不同，而假装 MAP 是正确的概括方式所毁掉的论文，比过拟合还多。

第 8 步

这套框架在你的研究中处于何处

贝叶斯框架能在三处给你带来具体而非审美上的收益：

  • 部署模型中的校准不确定性。 一个在分布外会说“我不知道”的传感器模型，比一个到处都说“0.97”的模型更安全。可靠性图 + 温度缩放 + 深度集成能带你走完大半路程；完整的贝叶斯深度学习则是有原则的极限。
  • 面向稀疏、结构化数据的层次模型。 患者、站点、传感器、语言、个体——凡是你拥有许多组、而每组只有少量观测之处，部分池化都远远胜过“每组一个模型”与“所有数据一个模型”。这是贝叶斯在处理具有区域结构的数据时的超能力。
  • 逆问题与物理信息机器学习。 能量分解、空气质量的源解析、卫星像元解混、睡眠分期估计——其中的未知量是高维潜变量，而前向模型只被部分已知。贝叶斯是逆问题的语言；其余一切都只是对它的近似。
最后总结。 后验是一个概率分布。要推理它并不需要新的数学——只需要耐心，计算贝叶斯法则右端的那个乘积。上面八个交互模块就是那一个乘积的八种版本。其余一切（MCMC、VI、GP、BNN）都是管道工程。
