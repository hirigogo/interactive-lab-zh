认识多元正态分布

你已熟悉钟形曲线。本文将展示它如何推广到二维、为何协方差矩阵掌控一切，以及当对一个变量取值以推断另一个变量时会发生什么。下文的每一个公式旁都配有交互式图形 — 拖动滑块即可实时观察数学结果的更新。

I. 一维：密度、面积与 68-95-99.7 法则

正态分布描述的是一个围绕中心值聚集、并向两侧对称衰减的随机变量。它完全由两个数确定：决定中心的均值 μ，以及决定宽度的标准差 σ。除此之外别无其他。世界上任何一条钟形曲线，只要已知这两个数，在平移与伸缩的意义下都是同一形状。

密度函数给出落在 x 附近任一特定取值处的相对可能性。它并不是概率 — 对于较窄的分布，它甚至可以大于 1。概率仅来源于两个端点之间的曲线下面积：

\[ f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\Bigl(-\frac{(x-\mu)^2}{2\sigma^2}\Bigr), \qquad P(a \le X \le b) = \int_a^b f(x)\,dx \]

公式中的指数项承担了全部作用。量 (x−μ)² / (2σ²) 以标准差为单位衡量 x 距中心有多远。在均值处，该指数为零，密度达到峰值。偏离一个标准差处，指数为 −½，故密度降至 e−0.5 ≈ 0.61 倍。偏离两个标准差处，指数为 −2，密度降至峰值的 e−2 ≈ 0.14。衰减十分迅速。

这便引出著名的 68-95-99.7 法则：约 68% 的概率质量位于均值的 ±1σ 之内，约 95% 位于 ±2σ 之内，约 99.7% 位于 ±3σ 之内。这些数值与具体的 μ 和 σ 无关 — 它们是钟形曲线形状的普适性质。你可在下图中调整区间端点加以验证。

具体例子。 设某气象站的温度传感器平均读数为 20.0°C（μ = 20），测量噪声为 σ = 0.5°C。则约 68% 的读数将落在 19.5°C 至 20.5°C 之间，而读数超出 18.5–21.5°C（±3σ）范围的情形出现比例低于 0.3%。这正是正态分布让你仅凭两个数即可作出的定量陈述。

值得注意之处。 观察随着 σ 增大峰值下降的现象。曲线下总面积恒为 1，因此把概率质量铺得更宽必然压低峰值。对标准正态分布（μ=0，σ=1），峰高为 1/√(2π) ≈ 0.399。当 σ=2 时，峰高减半。

标准化变量 z = (x−μ)/σ 可将任意正态分布化为标准正态分布。这不仅是查表所用的技巧 — 它是使高维情形变得可处理的关键概念性操作。在二维中，“偏离多少个标准差？”的类似物是 马氏距离，它考虑了不同方向上的离散程度可以不同这一事实。

II. 二维：协方差矩阵及其所掌控之物

现在设想同时测量两个量 — 例如学习时长与考试成绩，或带噪 GPS 给出的纬度与经度。每一对观测值都是平面上的一点。若两个坐标上的噪声大致服从高斯分布，则联合分布为二元正态分布。此时得到的不是一条钟形曲线，而是三维空间中一座钟形山峰。从上方俯视，该山峰的等值线为椭圆。

二元正态分布由五个数参数化：两个均值（μx， μy）、两个标准差（σx， σy）以及一个相关系数 ρ。这五个数被打包成一个均值向量与一个 2×2 的协方差矩阵：

\[ \mathbf{x} \sim \mathcal{N}\!\left( \boldsymbol{\mu},\; \Sigma \right), \qquad \boldsymbol{\mu} = \begin{bmatrix} \mu_x \\ \mu_y \end{bmatrix}, \qquad \Sigma = \begin{bmatrix} \sigma_x^2 & \rho\,\sigma_x\sigma_y \\ \rho\,\sigma_x\sigma_y & \sigma_y^2 \end{bmatrix} \]

解读协方差矩阵。 对角线元素 σx² 与 σy² 即你在一维中已熟知的方差 — 它们分别独立地掌控沿各坐标轴的离散程度。非对角元素 ρσxσy 即为协方差。它告诉你两个变量是倾向于同向增大（正）、反向变化（负），还是独立变动（零）。相关系数 ρ 不过是归一化到 −1 与 +1 之间的协方差。

为何是椭圆？ 二维情形的密度公式包含二次型 (x−μ)T Σ−1 (x−μ)。令该二次型等于一个常数，即得椭圆的方程。同一椭圆上的点具有相同的密度，故该分布的等值线为椭圆。Σ 的特征值决定椭圆各轴的长度，特征向量决定其倾斜方向。

\[ f(\mathbf{x}) = \frac{1}{2\pi\,|\Sigma|^{1/2}} \exp\!\Bigl( -\tfrac{1}{2} (\mathbf{x}-\boldsymbol{\mu})^\top \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu}) \Bigr) \]

前置因子 1/(2π|Σ|1/2) 是归一化常数 — 它保证密度在整个平面上的积分为 1。行列式 |Σ| 度量椭圆的 “体积”：行列式越大意味着离散程度越高，从而峰值密度越低，这与一维情形完全一致。

值得注意之处。 散点为当前分布的随机样本。嵌套椭圆是 1、1.8、2.45 与 3.1 个标准差（马氏距离）处的等值线。当 ρ=0 时，椭圆与坐标轴对齐 — 椭圆各轴与坐标轴重合。随着 |ρ| 增大趋近于 1，椭圆发生倾斜并变窄。当 ρ≈±1 时，全部概率质量集中于一条直线附近，两个变量彼此近乎成为确定性的函数。

特征值解释。 协方差矩阵 Σ 可分解为 Σ = QΛQT，其中 Q 为旋转矩阵（特征向量），Λ 为对角矩阵（特征值）。特征向量给出椭圆各轴的方向，特征值给出沿这些轴的方差。这一分解正是二元正态分布 “看起来像” 一个被旋转过的轴对齐高斯分布的原因：因为它本就恰恰如此。

具体例子

  • 学习时长与考试成绩（ρ≈0.7）：学习时间越长，成绩往往越高，但并非完全如此 — 椭圆向上倾斜，但仍具有相当的宽度。
  • 速度与行程时间（ρ≈−0.8）：速度越快，行程越短，因而呈向下倾斜。
  • 道路上 GPS 的纬度与经度：沿道路方向的不确定性远大于垂直于道路方向的不确定性，因而形成一个与道路方向对齐的很窄的椭圆。
  • 制造中的宽度与厚度（ρ≈0.9）：若生产线发生漂移，两个测量值将一同漂移，故椭圆又窄又倾斜。

III. 采样：将分布转化为真实数据

知道一个分布的公式是一回事，能够由它生成真实抽样则是另一回事。在实践中，每一次蒙特卡洛模拟、每一个贝叶斯后验样本，以及每一个生成模型，都依赖于高效采样的能力。对多元正态分布而言，其算法优雅简洁，且仅依赖一个核心思想：从简单的对象出发，再对其作变换。

  1. 抽取 一个由相互独立的标准正态变量构成的向量 z — 其每个分量都是独立的 N(0,1)。由此得到一个以原点为中心的球状分布。
  2. 求 矩阵 L 使其满足 LLT = Σ。此即协方差矩阵的 Cholesky 分解 — 只要 Σ 正定便存在，而对一个合法的协方差矩阵而言这始终成立。
  3. 计算 x = μ + Lz。乘以 L 将球状分布拉伸并旋转为正确的椭圆形状，再加上 μ 将其平移至正确位置。
\[ z \sim \mathcal{N}(\mathbf{0}, I), \qquad \mathbf{x} = \boldsymbol{\mu} + L\,z, \qquad LL^\top = \Sigma \]

为什么这样做有效？ 若 z 的协方差为 I，则 Lz 的协方差为 L · I · LT = LLT = Σ。这就是全部证明。期望的线性性给出正确的均值，协方差变换法则给出正确的离散程度。这正是线性代数与概率论如此自然地相契合的原因。

下图从你在第 II 节中配置的二元正态分布中抽取真实样本。每次点击 “重新抽样”，都会生成一组新的独立标准正态变量，并经 Cholesky 因子变换。注意样本均值与样本协方差如何随每次抽样而波动，在样本量较小时尤为明显。这就是抽样变异性，也是统计估计之所以必要的最根本原因。

值得注意之处。 当 n=20 时，样本估计值可能偏离甚远。 当 n=300 时，它们稳定下来并接近真实参数。这种收敛正是大数定律的体现。 试着把样本数量设为 20 并多次点击重新抽样。你会看到样本均值来回跳动，样本协方差矩阵在相邻抽样间变化明显。 然后设为 300 重复同样的操作 — 估计值会稳定得多。 收敛速率大致与 1/√n 成正比。

IV. 估计：由观测点拟合参数

在实践中，你极少已知 μ 与 Σ — 必须从数据中估计它们。对于高斯分布，最大似然估计具有极其简洁的形式：样本均值即数据点的平均，样本协方差即中心化数据外积的平均。

\[ \hat{\boldsymbol{\mu}} = \frac{1}{n}\sum_{i=1}^n \mathbf{x}_i, \qquad\qquad \hat{\Sigma} = \frac{1}{n}\sum_{i=1}^n (\mathbf{x}_i - \hat{\boldsymbol{\mu}}) (\mathbf{x}_i - \hat{\boldsymbol{\mu}})^\top \]

外积的作用。 对每个数据点，项 (xi−μ̂)(xi−μ̂)T 是一个 2×2 矩阵。其 (1,1) 元素为 x 方向偏差的平方，(2,2) 元素为 y 方向偏差的平方，非对角元素则为 x 与 y 方向偏差之积。对所有数据点取平均，对角线即得样本方差，非对角线即得样本协方差。此处并无黑箱 — 它字面上就是在对偏差平方取平均。

关于偏差的说明。 最大似然估计除以 n，得到的是协方差的有偏估计。无偏版本则除以 n−1（贝塞尔校正）。当 n 较大时二者差异可忽略。当 n 较小时，偏差通常是最不值得担心的问题。

下图展示一个小型玩具数据集。实线椭圆是使用样本均值与样本协方差拟合出的高斯分布，虚线椭圆则是生成该数据的真实分布。在图中任意位置点击即可添加新的数据点，并实时观察拟合椭圆的变化。在中心附近添加点会使估计更稳定；添加离群点则可能令椭圆大幅倾斜。

V. 边缘分布：投影掉一个坐标轴

边缘分布 回答的问题是：若我完全忽略两个坐标中的一个，余下的坐标单独看来是什么样子？形式上，你对想要遗忘的那个坐标方向对联合密度积分（求和）：

\[ f_X(x) = \int_{-\infty}^{\infty} f_{X,Y}(x,y)\,dy \qquad\Longrightarrow\qquad X \sim \mathcal{N}(\mu_x,\;\sigma_x^2) \]

对高斯分布而言，这一积分有一个引人注目的结果：边缘分布本身仍是高斯分布，其参数恰为均值向量中对应的分量与协方差矩阵对角线上的对应元素。计算边缘分布无需 ρ。X 的边缘分布仅依赖 μx 与 σx²；Y 的边缘分布仅依赖 μy 与 σy²。

这与直觉相悖。 你或许会以为，若两个变量相关，其中一个的边缘分布应在某种程度上反映这种相关性。事实并非如此。相关性掌控的是联合分布的形状 — 它决定椭圆如何倾斜 — 但当把这个椭圆投影到单一坐标轴上时，无论倾斜程度如何，阴影的宽度都相同。不妨一试：回到 第 II 节，在保持 σx 与 σy 不变的情况下改变 ρ，观察下方的边缘分布曲线保持不变。

从几何上看，边缘分布是二维分布投影到单一坐标轴上的 “影子”。设想有一束光垂直照射到 xy 平面上，观察 x 轴上形成的轮廓。该轮廓的形状即 x 的边缘分布。无论你如何倾斜椭圆，只要其水平方向的范围不变，影子便不变。

为何这一点重要。 在许多应用中，你一次只能观测到一个变量。若你查看的是某位患者的血压而不知其胆固醇水平，你看到的便是边缘分布。边缘分布告诉你该变量在孤立状态下的离散程度，却丢弃了全部关于变量间关系的信息。而条件分布所恢复的，恰恰正是这些关系信息。

VI. 条件分布：高斯版本的 “在给定…之下”

条件分布 回答的问题比边缘分布尖锐得多：若我已知 X 取某一特定值 x0，那么关于 Y 我能说些什么？对高斯分布而言，答案仍是高斯分布，但有两点具体变化：

\[ Y \mid X = x_0 \;\sim\; \mathcal{N}\!\left( \underbrace{\mu_y + \rho\,\frac{\sigma_y}{\sigma_x}(x_0 - \mu_x)}_{\text{条件均值}},\;\; \underbrace{(1-\rho^2)\,\sigma_y^2}_{\text{条件方差}} \right) \]

条件均值发生平移。 它不再停留在 μy，而是移动一段与 x0 偏离 μx 的程度成正比的量，并由回归系数 ρσy/σx 缩放。这恰好 就是 Y 对 X 的最小二乘回归直线的斜率。随着 x0 变化，条件均值描出一条直线 — 而这条直线正是回归直线。

条件方差收缩。 它由 σy² 缩减为 (1−ρ²)σy²。因子 (1−ρ²) 是 Y 的方差中未被 X 解释的比例。当 ρ=0 时，没有方差被解释，条件分布等于边缘分布。当 |ρ|=1 时，全部方差均被解释，条件分布退化为一个点 — 若你精确已知 X，便精确已知 Y。

与 R² 的联系。 在线性回归中，R² 是被预测变量解释的方差比例。对二元正态分布而言，R² = ρ²。条件方差等于 (1−R²) 乘以边缘方差。因此，简单线性回归的全部机制其实早已潜藏于二元正态分布之中 — 条件分布字面上就是回归所计算的对象。

下图在联合分布上添加了两条切片线：x0 处的竖直切片（揭示 Y|X）与 y0 处的水平切片（揭示 X|Y）。拖动切片线或使用滑块。将每条条件曲线与其边缘分布（以青色显示）比较：条件分布总是 更窄或相等，绝不会更宽。

值得注意之处。 在 ρ 为高正值时把 x0 移到 +2 个标准差处。Y 的条件均值跃升至远高于 μy 的位置，条件曲线也变得明显比边缘分布更窄。现在令 ρ=0。条件分布与边缘分布变得完全相同：观测 X 对推断 Y 毫无帮助。这就是高斯变量独立性的操作性定义。

封闭性。 将高斯分布关于某一部分变量取条件后得到的仍是高斯分布，这是该分布族最重要的代数性质。它是 Kalman 滤波得以成立的原因（预测与更新皆为高斯运算），是高斯过程能给出闭式后验的原因，也是贝叶斯线性回归拥有精确解的原因。每当你看到一个模型说 “假设数据服从高斯分布” 时，这一封闭性通常才是其真正的动机。

VI½. 学生屡屡中招的三个误区

高斯分布性质过于良好，以致学生常将其性质推广到一般概率论。其中三种推广是错误的，下面给出简要纠正。

误区 1 —— 不相关即独立

仅对联合高斯变量成立。 对其他分布而言，零相关仅意味着不存在线性关系。取 Y = X2，其中 X ∼ N(0,1)：cov(X, Y) = E[X3] = 0，但 Y 是 X 的确定性函数 —— 依赖关系是完全的。高斯分布之所以特殊：仅对它而言，零相关才强制推出独立。

误区 2 —— 边缘分布决定联合分布

仅有边缘分布还不够，你还需要协方差。 ρ = 0.8 的联合高斯分布与 ρ = −0.8 的联合高斯分布，其 X 与 Y 的边缘分布完全相同。边缘分布是联合分布向各坐标轴所作的投影（影子）；影子丢失了全部关于两个变量如何协同变化的信息。这正是我们无法由两个一维直方图还原出二维分布的原因。

误区 3 —— 取条件总能降低不确定性

对高斯分布（以及许多性质良好的分布）成立；但并非普适规律。 对二元正态分布而言，条件方差 ≤ 边缘方差恒成立 —— 它恰为 (1 − ρ2)σ2。但在一般概率论中，对某个变量取条件反而可能增大 另一个变量的方差（辛普森悖论是最典型的例子）。切勿不经检验便把高斯分布的直觉带入非高斯情形。

这三条都值得按名称记牢，因为每一条都对应着学生建模时确实会引入的错误。前两条为协方差矩阵提供了动机（联合结构并非与边缘分布冗余）。第三条则提示：每当对一个非高斯协变量取条件时，都需谨慎推理。

VII. 小结与联系

密度不是概率
某点处密度的取值是相对可能性，而非概率。概率是两点之间曲线下的面积。密度可以大于 1。
一维中两个参数掌控一切
μ 决定中心，σ 决定宽度。68-95-99.7 法则让你无需计算任何积分即可快速估算概率。
二维中协方差矩阵就是全部
对角线元素是方差，非对角元素是协方差。Σ 的特征值与特征向量直接给出椭圆的形状与朝向。
采样 = 变换标准正态分布
抽取 z ~ N(0,I)，计算 x = μ + Lz，其中 LLT = Σ。Cholesky 因子 L 负责拉伸与旋转。每一个蒙特卡洛采样器都以这种方式生成多元正态样本。
最大似然估计不过是取平均
最大似然均值即样本平均。最大似然协方差即中心化观测值外积的平均。无需梯度下降，无需迭代 — 只需求和。
边缘分布忽略相关性
无论相关性多强，X 的边缘分布仅依赖 μx 与 σx²。边缘分布是投影，而投影会丢弃关系信息。
条件分布即回归
对 X=x0 取条件得到 Y 的高斯分布，其均值沿回归直线变化，方差为 (1−ρ²)σy²。条件分布正是 线性回归所计算的对象。
封闭性才是真正的超能力
高斯分布经边缘化、取条件以及线性组合后仍为高斯分布。这一封闭性正是该分布族占据主导地位的原因：Kalman 滤波、高斯过程、贝叶斯线性回归与因子分析皆依赖于此。

后续方向

更高维。 上述一切均可直接推广：μ 变为 d 维向量，Σ 变为 d×d 矩阵，等值线变为椭球面。边缘分布与条件分布仍为高斯分布，公式形式相同（只是涉及 Σ 的子矩阵）。

高斯过程。 GP 是定义在函数 之上的分布，其定义性质为：任意有限个函数值构成的集合服从联合高斯分布。对已观测数据点取条件，正是第 VI 节中的条件分布公式应用于潜在无穷维协方差结构的结果。

Kalman 滤波。 线性动力系统在每个时间步的状态服从高斯分布。预测步是边缘化（向时间前方投影），更新步是取条件（纳入新的观测）。两种运算都保持高斯性，这正是 Kalman 滤波既精确又高效的原因。

最大熵。 在均值与协方差给定的所有分布中，高斯分布的熵最大 — 它作出的额外假设最少。这就是以高斯分布作为不确定性默认模型的信息论依据。
