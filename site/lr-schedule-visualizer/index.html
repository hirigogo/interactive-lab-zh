为何 Transformer 需要预热

    

      Adam 的二阶矩估计 v̂_t 在第 1 步时既小又含噪。用 √v̂_t 作除数会极大地放最初若干步。与此同时，随机初始化的注意力会产生尖峰状的分布 — 少数注意力头中出现较大的早期梯度。二者叠加，以满学习率冷启动便会产生巨大而不稳定的初始步，损失随之发散。
    

    

      预热在训练的前 1–10% 内将学习率从 0 线性升至峰值。一旦 v̂_t 经过若干步趋于稳定、注意力也已变得分散，便可安全地维持峰值学习率。
    


    
现代学习率调度的四阶段解剖

    
    
      
  1. 预热（0 → 峰值）。 在总步数的 1–10% 内线性上升。稳定 Adam 的矩估计，并让初始化有时间趋于平稳。
    2. 
      
  2. 峰值（恒定或近乎恒定）。 训练的主体部分。一些方案（Llama、Chinchilla）保持恒定；另一些（余弦、Noam）则在预热结束后立即开始衰减。
    3. 
      
  3. 衰减（峰值 → 近零）。 余弦、线性或阶梯。具体形状不如幅度重要 — 关键在于最终学习率要足够低。
    4. 
      
  4. 尾部（约 0）。 可选。最后阶段以低学习率进行收尾微调。在 LLM 预训练中属标准做法。
    5. 
    


    
按使用场景分类的调度速查表

    
    
      
  • ImageNet 上的计算机视觉（ResNet、ViT）。 在 100 个轮次内做余弦衰减；ResNet 无需预热，ViT 约需 5 个轮次的预热。峰值学习率约 0.1（SGD）或 1e-3（AdamW）。
    • 
      
  • LLM 预训练。 线性预热约占总词元数的 1%，随后余弦衰减至峰值的 10%。峰值学习率从约 3e-4（小模型）到约 1e-4（70B 以上）。
    • 
      
  • LLM 的 SFT / 指令微调。 短线性预热（约 50 步），余弦衰减至零。峰值学习率约为 2e-5 至 5e-5。相比预训练低得多，以避免灾难性遗忘。
    • 
      
  • LoRA 微调。 恒定或单次余弦周期。峰值学习率约 1e-4。适配器参数能比基础参数承受更高的学习率。
    • 
      
  • 目标检测 / 分割。 阶梯调度（在训练进度 60%、80% 处乘以 0.1）。这是经典的 DETR / Mask R-CNN 方案。
    • 
      
  • 扩散模型训练。 恒定学习率 + 权重 EMA。隐式的「衰减」主要由 EMA 承担。
    • 
    


    
单周期、余弦与恒定三者对比

    

      你在生产实践中会遇到的三种范式：
    

    
    
      
  • 恒定学习率 + 结尾衰减。 为 Chinchilla 及近期的 Llama 训练所采用。在训练时长经过良好调校时，其经验表现与余弦相当；对于超长训练，其行为更易于分析。
    • 
      
  • 余弦退火（Loshchilov & Hutter，2017）。平滑衰减；是 HuggingFace Trainer 与 PyTorch Lightning 中的默认选项。带重启的余弦（“SGDR”）会周期性地回到峰值 — 在 2022 年之前流行于视觉领域，如今在 LLM 中基本已被弃用。
    • 
      
  • 单周期（Leslie Smith，2018）。 学习率与动量的联合扫掠 — 短预热、长余弦衰减、极低的尾部。对于短训练过程（少于 1000 个轮次）效果强劲。对 LLM 而言多已成为历史，但对小规模 CNN 训练仍有价值。
    •
