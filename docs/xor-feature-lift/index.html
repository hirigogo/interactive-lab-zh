图形说明了什么

非线性从来不在分类器里。

A

任何直线都无法做到

假设某条直线把两个蓝色角点 (1, 1) 与 (−1, −1) 都放在正侧。半平面是凸集，故它也包含二者的中点，即原点。对两个橙色角点 (1, −1) 与 (−1, 1) 施以同样的论证，则原点落在负侧。矛盾。

问题不在训练。逻辑损失关于 (w, b) 是凸的，故梯度下降能到达全局最优；而在对称的 XOR 上，该最优解为 w = 0：处处预测 0.5，损失为 ln 2。

B

一列特征即可解决

在角点上，新列 x1x2 对蓝色取 +1、对橙色取 −1，因而它自身就能分开两类。权重 (0, 0, −1) 给出 z = −x1x2：蓝色上 p = σ(−1) ≈ 0.27，橙色上 σ(+1) ≈ 0.73；增大 w3 可使二者同时更锐利。

在特征空间中，该边界是平面 u3 = 0。加入乘积特征并训练，观察平面如何稳定在其附近。

C

同一条边界，两种视角

在特征坐标下，边界为 b + w1u1 + w2u2 + w3u3 = 0，按构造即为一个平面。代入 u3 = x1x2 并求解得 x2 = −(b + w1x1) / (w2 + w3x1)，这是一条双曲线，其渐近线为 x1 = −w2/w3 与 x2 = −w1/w3。

点击侧视可将平面看作一条直线，再点击俯视可看到其迹线即左侧的曲线。同一个对象，两种投影。

D

网络学习 φ

干扰特征 x1² + x2² 在每个角点上都等于 2，因而无助于分类：有用的特征必须在不同类别间取值不同。ReLU 特征 max(0, x1 + x2 − 1) 是权重为 (1, 1)、偏置为 −1 的单个隐藏神经元，此处由手工设定。它标记出 (1, 1) 角点，与那条直线配合即可解出 XOR。

隐藏层就是这样一组单元的集合，其权重由同样的梯度下降学习得到。ReLU 演练场展示了这一过程。
