交互式讲解

视觉语言模型：端到端全流程

现代 VLM 由三个彼此衔接的模块构成（视觉编码器、投影器、语言模型），并经历四个训练阶段（对比学习、图像奠基的语言建模、指令微调、偏好对齐）。一个实时运行的 mini-CLIP 使对比学习阶段具象可感；最后我们讨论真实 VLM 在热成像数据上陷入的定标陷阱。

约 22 分钟 多模态 · CLIP · 指令微调
前言

架构概览：三个模块

每一个现代 VLM —— LLaVA、Qwen-VL、Pixtral、GPT-4o、具备视觉能力的 Claude 3.5 —— 都具有相同的形态：

  • 视觉编码器。 通常为经 CLIP 或 DINOv2 预训练的 ViT。输入一幅图像，输出一串 patch 嵌入（例如对 224×224 的图像、patch 尺寸为 14 时，得到 256 个 1024 维的词元）。
  • 投影器。 一个规模较小的 MLP（有时为交叉注意力模块），将视觉嵌入映射到 LLM 的隐藏维度，并（通常）通过池化或 Q-Former 式的学习式查询来减少词元数量。
  • 语言模型。 一个预训练的 decoder 式 LLM（Llama、Qwen、Mistral、GPT-OSS）。它接收拼接在文本词元流之前的投影后图像词元，并以自回归方式生成输出。
一句话概括。 所谓 VLM，就是一个被教会了阅读另一种「语言」—— patch 嵌入的语言 —— 的语言模型。神奇之处主要在编码器，智能之处主要在 LLM，而投影器则是位于二者之间、拥有 6000 万参数的翻译器。
第 1 步

阶段 1 —— 对比式图文对齐（CLIP）

在组装 VLM 之前，视觉编码器通常需要与文本对齐。标准做法是对比学习：训练图像编码器 $f_I$ 与文本编码器 $f_T$，使相匹配的（图像，描述）对在余弦相似度上彼此接近，而不相匹配的对彼此远离。

$\tau$ 是可学习的温度参数。该损失是对称的（图像到文本与文本到图像两个方向的交叉熵，再取平均）。在从网络抓取的 4 亿以上图文对上进行训练，可学得一套极为通用的视觉词汇 —— CLIP 无需在训练中见过任何带标签的 ImageNet 图像，即可在 ImageNet 上取得 76% top-1 的零样本分类精度。

观察要点。 在大约 50 步之内，相似度矩阵的对角线应开始比非对角线更亮。将 τ 调得极低（例如 0.05），训练会变得不稳定（梯度爆炸）；将 τ 调得极高（例如 1），损失则永远无法区分各对（在 $\log K$ 附近饱和）。真实 CLIP 使用的可学习 τ 初始化为 $0.07$。
第 1½ 步

图像与语言的接口 —— 投影器的设计方案

一旦视觉编码器完成对齐，每个 patch 都成为约 1024 维的特征向量。对 224×224 的图像、patch 尺寸为 14 时，共得到 256 个这样的词元；而 LLM 可能希望它们处于 4096 维的隐藏空间中，且未必需要全部 256 个。投影器正是位于编码器与 LLM 之间、同时完成这两项任务的小型网络。实践中主流设计有四类：

  • 线性层 / 2 层 MLP（LLaVA-1.0、LLaVA-1.5）。 词元一一对应：每个 patch 嵌入映射为 LLM 空间中的一个图像词元。成本最低，效果却出奇地强；但图像词元数等于 patch 数，在高分辨率下会成为上下文长度的主要负担。
  • Perceiver 重采样器 / Q-Former（Flamingo、BLIP-2）。 $K$ 个学习式查询词元对 patch 特征做交叉注意力；无论图像分辨率如何，输出恰好为 $K$ 个图像词元。可节省计算与上下文：约 32 个查询词元即可替代 576 个 patch 词元。代价是需要单独训练一个模块。
  • 在 LLM 内部使用交叉注意力（Flamingo、IDEFICS）。 在 LLM 内部 插入专门的交叉注意力层，用于关注图像词元。如此，LLM「看见」图像，却无需为它消耗自注意力的预算。
  • 词元打包 + AnyRes / 动态分块 （LLaVA-NeXT、Qwen-VL-2.5、GPT-4o、Pixtral）。 将高分辨率图像切分为若干瓦片，每个瓦片是一幅子图像，其瓦片特征被拼接起来。如此，模型无需具备 1344 像素感知能力的编码器，也能处理 1344×1344 的图像。

这一选择会带来可度量的后果：

设计方案图像词元数可训练参数量优势权衡
线性层 / MLP= patch 数（256–576）~10M最简单；保留空间信息上下文开销大

第 2 步

阶段 2 —— 图像奠基的语言预训练

在编码器完成对齐之后，便可接入语言模型。投影器随机初始化；编码器与 LLM 则加载预训练权重。

训练数据为图文对。损失为描述文本上的标准下一词元交叉熵，并将图像词元作为前缀上下文。编码器与 LLM 均被冻结，仅训练投影器。此阶段成本低廉（6000 万参数），在少量 GPU 上即可运行，所得到的模型能够描述图像，但几乎无法遵循指令。

为何在此处冻结 LLM。 投影器初始为随机状态；若在此阶段让梯度流入 LLM，LLM 已有的语言能力会崩溃（灾难性遗忘）。阶段 2 的作用是先将投影器纳入 LLM 的隐藏状态分布之中。
第 3 步

阶段 3 —— 指令微调

此时模型已能描述图像，却无法就图像回答问题或遵循指令。阶段 3 通过一份精心构建的三元组数据集 $(\text{image}, \text{instruction}, \text{response})$ 来解决这一问题。 例如：「数出这张照片中的人数。」「这支温度计上的读数是多少？」「编写 Python 代码，绘制出该图像中的图表。」

损失仅计算响应词元上的交叉熵（图像词元与指令词元被掩蔽）。投影器继续训练；LLM 此时也开始训练， 但学习率较低（最常见的实现方式是在 LLM 上叠加 LoRA）。

规模带来的变化。 前沿 VLM（Gemini、GPT-4o、Claude）在万亿词元的规模上将阶段 1-3 融合在一起，编码器、投影器与 LLM 自训练早期即联合训练。上文所述的冻结式流程是学术预算下的 LLaVA 风格做法；对于实验室中构建的任何领域专用 VLM，它仍然是恰当的起点。
第 4 步

阶段 4 —— 偏好对齐（RLHF / DPO）

经指令微调的模型仍会给出错误内容、含糊其辞，或做出无益的拒绝。阶段 4 收集「这个回答优于那个回答」的偏好对（来自人工或更强的模型），使模型与这些偏好对齐。

  • RLHF。 在偏好对上训练奖励模型；再用 PPO 微调 VLM，最大化奖励并减去相对 SFT 模型的 KL 惩罚。
  • DPO（直接偏好优化）。 一种跳过奖励模型的闭式替代方案：直接优化隐式奖励。成本更低，效果往往相当。
  • RLAIF。 使用更强的模型作为偏好标注者。这已成为中等规模开源 VLM 的主流做法。
第 4½ 步

微调 VLM —— 真正可行的方案

多数实验室并不从头 训练 一个 VLM，而是对现有模型进行微调。各选项构成一个成本与灵活性的阶梯：

  • 仅做提示工程。 无需成本；对基座模型已具备能力的零样本任务有效。
  • 检索增强（RAG）。 增加一个领域图像/描述的向量数据库；在推理时检索并前置拼接。无需训练；有助于长尾知识。
  • 在 LLM 上使用 LoRA（默认选择）。 在 LLM 的注意力与 MLP 权重上添加 $r$ 阶低秩增量。约占 LLM 参数的 1%；单卡 GPU 即可容纳。 常见目标模块：至少为 $\{\,W_q, W_v\,\}$； 若需更强的适配，则为 $\{\,W_q, W_k, W_v, W_o, W_{up}, W_{down}, W_{gate}\,\}$。
  • 对投影器 + LLM 做全量微调（不使用 LoRA）。 质量最佳，需多卡 GPU。当领域偏移较大时（医学影像、卫星图像、热成像）必须采用。
  • 全量编码器 + 投影器 + LLM。 当模态是全新的（深度、音频、点云）时需要如此。 成本：在 $\le$10 亿参数的基座上约需 500-2000 GPU 小时。

实用方案（单卡 GPU 实验室微调）

  • 主干模型。 以 Llama-3.2-Vision-11B 或 Qwen-VL-7B 作为冻结编码器的基座。二者均随附指令微调后的权重。
  • 适配器。 在每一层的 $\{W_q, W_k, W_v, W_o\}$ 上使用 LoRA 秩 $r = 16$；$\alpha = 32$； dropout 为 $0.05$。
  • 数据。 5 万至 5 万条领域图像-指令-回答三元组。若你只有图像-标签对，可用更强的 VLM 合成指令。 混入 5–10% 的基础指令数据以防止灾难性遗忘。
  • 优化器。 AdamW，LoRA 参数的学习率为 $1{\times}10^{-4}$，投影器的学习率为 $1{\times}10^{-5}$ （若未冻结）。采用余弦调度，预热占 3%，训练 1–3 个 epoch。
  • 评估。 使用与训练相同提示分布的留出验证集；跟踪 exact-match、自由文本的 BLEU/Rouge， 以及一个留出的幻觉探测集。
  • 需警惕的缺陷。 冻结的图像词元仍在消耗上下文预算；训练与评估之间的图像预处理不一致（隐形杀手）； 基座与你的提示之间的 tokenizer 模板漂移。
第 4¾ 步

评估 —— 各基准实际衡量的内容

若不明确评估方式，受过训练的 VLM 所报出的数值毫无意义。2024-2026 年的标准评测如下：

基准考察内容格式注意事项
VQAv2 / GQA / OK-VQA（视觉问答）开放式视觉问答单词 / 短语提示模板化；已饱和
MMBench / MMVet（综合能力）综合能力评测集多选 + 自由文本评估本身即为一次（评判）LLM 调用
MMMU（多学科推理）大学水平的多学科推理多选侧重图表理解
POPE / HallusionBench（幻觉探测）物体与场景上的幻觉是/否，自由文本存在极性偏差；需要均衡的「否」样本
ChartQA / DocVQA（图表与文档）图表与文档理解数值 / 抽取式依赖 OCR 读取；高分辨率瓦片打包有助益
MathVista / MathVerse（视觉数学）视觉数学数值数值上的定标；工具使用效果更佳
MMMU-Pro / Reason-Bench（扰动鲁棒性）图像扰动下的推理多选对裁剪 / 旋转 / 颜色变化的鲁棒性
RefCOCO / GroundedVQA（视觉定位）视觉定位（输出边界框）坐标坐标格式差异极大
BLINK / Video-MME（纯视觉与视频）纯视觉与视频任务多选视频模型继承不同的偏差

选取 2 个综合性基准（MMBench + MMMU）与 1 个幻觉探测集（POPE）作为实验室的常规指标；在每个 checkpoint 上都报告这三项结果。最常见的误导是「我们在 VQAv2 上超过了 GPT-4」—— VQAv2 自 2022 年起已饱和，如今几乎无人再在该基准上报告结果。

第 4⅞ 步

图文检索 —— 实时展示 recall@K

经 CLIP 对齐的编码器还附带免费的检索能力：取一条文本查询，将其嵌入，再找出最接近的图像嵌入。 Recall@K 指真实图像出现在检索结果前 K 位的测试查询所占比例。可观察到第 1 步中的实时 mini-CLIP 给出其自身的检索矩阵。

第 5 步

热成像陷阱（以及基于工具使用的解决方案）

真实 VLM 在热成像上会惊人地失败。原因在于定标：热传感器输出的每个像素都是原始温度值，随后被映射为供人眼观看的色彩映射。 两幅对 VLM 而言外观完全相同（伪彩色调色板相同）的热图像，其绝对温度可能相差悬殊 —— 因为 VLM 只看到颜色，看不到元数据。

解决之道并非更大的 VLM，而是一个工具使用回路：

  1. VLM 查看图像。
  2. VLM 发出一次工具调用：「请给出像素 (i, j) 处的温度。」
  3. 工具读取原始辐射度 TIFF，并返回以开尔文为单位的数值。
  4. VLM 基于数值进行推理，而非基于颜色。

这正是 工具增强的热成像 VLM 以及热成像 VLM 基准评测背后的研究方向 —— 它具体地证明了：主流 VLM（GPT-4、Claude、Gemini）在那些工具增强的小模型可以成功的任务上反而失败。这一经验可推广： 任何「像素外观相同但含义不同」的模态（热成像、高光谱、深度、音频频谱图）都需要一个工具层。

最终要点。 VLM 是一个学会了阅读像素词元的语言模型。其训练流程已被充分理解；尚待解决的问题是对齐、数值上的幻觉，以及模态特有的定标。 在实践中，模态特有的定标正是大部分研究回报之所在。
