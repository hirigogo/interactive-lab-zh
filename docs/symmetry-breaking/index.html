这些指标的含义

问题在于表征能力的丧失。

A

完全相同

全部四个激活都是同一列。秩始终为 1，间距始终为 0，因此输出仅是一个 ReLU 特征的缩放副本。在这个 XOR 集合上，它通常稳定在 75% 附近：有一个象限始终错误。

B

轻微扰动

相等约束消失了。彩色的折线得以分开，特征秩升到 1 以上。打破对称性是必要的；但它并不保证这个特定的起点一定能找到最优的 XOR 解。

C

相互独立

各不相同的起始方向使梯度下降能够组合多个半平面。在此处的固定种子下，四个交替的 XOR 区域都被学到，测得的准确率达到 100%。
