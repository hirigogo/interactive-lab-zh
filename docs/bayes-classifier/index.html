亲手构建一个贝叶斯分类器

若你已知每个类别的真实分布，那么最优的分类器是什么？ 贝叶斯法则给出了确切答案：构造后验 $p(Y=1\mid x) \propto p(x\mid Y=1)\,p(Y=1)$，并预测概率更大的那个类别。 这里我们用两个高斯分布与一个先验把它构建出来——并观察最优 决策边界如何恰好出现在后验穿过二分之一之处。

约 10 分钟 深度学习 · 概率 · 分类
前言

似然乘以先验，再归一化

把每个类别建模为数据的生成器。类别 0 从 $p(x\mid Y=0)=\mathcal{N}(\mu_0,\sigma_0^2)$ 生成数据点；类别 1 从 $p(x\mid Y=1)=\mathcal{N}(\mu_1,\sigma_1^2)$ 生成数据点。再添加一个关于类别 1 有多常见的 先验信念 $\pi = p(Y=1)$。贝叶斯法则把生成器反过来， 在给定一个数据点 $x$ 时告诉你每个类别的概率：

$$p(Y=1\mid x) = \frac{\overbrace{p(x\mid Y=1)}^{\text{likelihood}}\,\overbrace{\pi}^{\text{prior}}} {p(x\mid Y=1)\,\pi + p(x\mid Y=0)\,(1-\pi)} .$$

凡后验超过 $\tfrac12$ 之处即预测为类别 1。 而后验恰好等于 $\tfrac12$ 的那些点构成的集合就是决策边界。 平均而言，没有任何分类器能胜过它——它就是 贝叶斯最优规则，是衡量其他一切方法的标尺。

回报

决策边界从何而来

把后验设为 $\tfrac12$，等同于令两个先验加权似然相等： $\pi\,p(x|Y{=}1) = (1-\pi)\,p(x|Y{=}0)$。 对两个高斯分布取对数，边界条件就变成关于 $x$ 的二次式：

$$-\frac{(x-\mu_1)^2}{2\sigma_1^2} - \log\sigma_1 + \log\pi = -\frac{(x-\mu_0)^2}{2\sigma_0^2} - \log\sigma_0 + \log(1-\pi).$$
  • 方差相等（$\sigma_0=\sigma_1$）：$x^2$ 项相互抵消，只剩一条单一的线性边界。这正是逻辑回归 / 线性判别分析的决策规则。
  • 方差不等：$x^2$ 项保留下来——一个真正的二次式，最多有两个根。这就是二次判别分析。
  • 先验仅通过 $\log\frac{\pi}{1-\pi}$ 进入边界，表现为一个加性平移—— 因此改变先验只会平移边界，而不改变其形状。
要点。 分类器不过是一条比较后验的规则。生成式模型 （如此处所示）通过建模 $p(x|y)$ 并应用贝叶斯法则到达那里；判别式模型 （逻辑回归、神经网络）则直接建模 $p(y|x)$。二者追逐的 都是你在上方拖动的那条同一条贝叶斯最优边界。
