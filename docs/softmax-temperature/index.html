Softmax & 温度

softmax 函数将原始分数转化为概率。温度旋钮 $T$ 控制该分布的尖锐或平坦程度 —— 它与驱动大语言模型创造力以及蒸馏中知识传递的是同一个旋钮。本页通过实时公式、实时采样与实时熵，帮你建立起直觉。

约 12 分钟 深度学习 · 损失函数 · 采样
前言

softmax 为何存在

你网络的最后一层输出 logit：$K$ 个类别上的原始实值分数 $z_1, z_2, \ldots, z_K$。它们可以为负，可以大于 1，可以是任何值。但要进行分类或从模型中采样，你需要一个 概率分布：即和为 1 的、位于 $[0,1]$ 中的数。

你大可直接归一化：$p_k = z_k / \sum_j z_j$。但只要有任何一个 $z_k$ 为负，这就会失败。你也可以先平移再归一化。但为何偏偏选那个平移量？softmax 才是更有原理依据的答案：它自然地由最大似然框架导出，并且具有一个漂亮的梯度。

$$p_k = \mathrm{softmax}(\mathbf{z})_k = \dfrac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

取指数保证了正值。除以总和保证了它们加起来为 1。我们将在第 2 步遇到的「温度」版本，在取指数之前对 logit 进行缩放 —— 随之而来的是现代深度学习中最有用的旋钮之一。

第 2 步

温度旋钮

现在我们加入一个旋钮。在取 softmax 之前，将每个 logit 除以一个正数 $T$：

$$p_k = \dfrac{e^{z_k / T}}{\sum_{j=1}^{K} e^{z_j / T}}$$
  • $T \to 0$： 最大的 logit 占主导。分布变为独热（argmax）。
  • $T = 1$： 标准 softmax。
  • $T \to \infty$： 所有 logit 都变为 $\approx 0$。分布变为均匀分布。

因此 $T$ 在「总是挑选最好的」与「均匀随机地挑选」之间平滑地插值。滑动下面的温度，实时观察分布的变化。

熵 $H = -\sum p \log p$ —
可能的最大值（均匀） —
置信度（最高概率） —
与熵的联系。 随着 $T$ 增大，分布变得平坦，其熵 $H$ 上升趋向 $\log K$（均匀分布的熵）。当 $T \to 0$ 时，$H \to 0$。温度实际上就是输出分布之熵上的一个旋钮。
第 3 步

采样：把概率转化为抽取

一个概率分布不过是一份产生随机性的配方。要从 softmax 中 采样，你抽取一个均匀随机数 $u \in [0,1]$，然后沿累积概率前进，直到超过 $u$。

$$\text{Pick class } k \text{ if } \sum_{j < k} p_j \le u < \sum_{j \le k} p_j$$

点击下面的 抽取一个样本。一条橙色竖线在位置 $u$ 处落到累积条上，它落入的类别即为抽中结果。试几次。现在把温度调高 —— 你会看到每个类别有时都会被抽中。把它调低 —— 总是同一个类别。

为何这很重要。 当一个 LLM「写出下一个词」时，发生的正是这件事：模型输出词表上的 logit，softmax 将其转化为概率，然后采样出下一个词元。低 $T$ → 稳妥、重复的文本。高 $T$ → 有创意但有时不连贯。你刚刚操控的正是 ChatGPT 作为「temperature」暴露出来的那个旋钮。

第 5 步

温度在实践中的出现场合

场景 $T$ 的作用 典型取值
LLM 文本生成 控制生成词元的创造力与连贯性之间的权衡 0.7 – 1.0（有创意），0.0 – 0.3（确定性）
知识蒸馏 较高的 $T$ 揭示教师模型软 logit 中的「暗知识」 $T \approx 4$（Hinton 等，2015）
扩散模型的无分类器引导 扮演类似的角色：以保真度换取多样性 引导尺度 $w \approx 3-7$
强化学习（玻尔兹曼探索） 选择动作：高 $T$ 探索，低 $T$ 利用 从高到低退火
校准 单个学得的 $T$ 对过度自信的模型输出进行重新缩放 通常 $T > 1$（温度缩放）

第 6 步

人们对 softmax 常犯的三个错误

误区

「softmax 的输出就是校准良好的概率。」
它们之和为 1，所以看起来像概率。但现代深度网络通常 过度自信 —— 最大的 softmax 值远高于模型在这些样本上的真实准确率。校准（如学得的温度缩放）可以修正这一点。

误区

「你应该先应用 softmax，再用交叉熵损失。」
并非如此。PyTorch 的 CrossEntropyLoss 会在内部施加 softmax，计算两次会得到错误的梯度。请直接传入原始 logit。

误区

「温度越低总是越准确。」
对于贪心解码（$T=0$），确实如此 —— 但若要在整个分布上评估，校准良好的概率（$T \approx 1$）能给出更好的不确定性估计，以及更好的下游流水线行为。

最终总结。 softmax 是将无界分数转化为概率分布的典范方式。温度参数 $T$ 通过重塑该分布的熵，在确定性于多样性之间平滑权衡。你现在知道了每个 LLM API 里的那个滑块究竟在做什么。
附赠

数值稳定性 —— 减去最大值的技巧

朴素的 softmax $e^{z_i} / \sum e^{z_j}$ 在 $z_i \gtrsim 700$（float64）和 $\gtrsim 88$（float32）时会溢出。每一个生产级实现都会在取指数之前减去最大的 logit：

softmax(z)i = exp(zi − max(z)) / Σj exp(zj − max(z))

数学结果完全相同（常数被抵消），但现在最大的指数恰好为 0，因此总和介于 1 与 $n$ 之间，永不溢出。在 torch.softmax / numpy.softmax 内部已经为你做好了这件事；如果你要从头编写 softmax（例如一个自定义 CUDA 核），这是你需要做的第一件事。

同样的技巧给出 logsumexp(z) = max(z) + log Σ exp(z − max(z))，它是稳定的交叉熵与对数概率计算的基本构件。

附赠

softmax 的替代方案 —— sparsemax、entmax、Gumbel

  • Sparsemax（Martins & Astudillo，2016）。将 logit 投影到单纯形上 —— 产生一个含若干精确零值的稀疏概率向量。在你需要硬性且可解释的选择的注意力头中很有用。
  • Entmax-α（Peters 等，2019）。在 softmax（$\alpha = 1$）与 sparsemax（$\alpha = 2$）之间插值。是一个单参数族。
  • Gumbel-softmax（Jang 等，2017；Maddison 等，2017）。向 logit 加入 Gumbel 噪声，再以低温度做 softmax —— 产生近似独热的、且 可微 的样本。是离散隐变量的标准重参数化技巧。
  • Top-k / 核采样（top-p）。 在采样前将 softmax 的支撑集限制在前 $k$ 个词元（或和为 $p$ 的最小集合）。是现代 LLM 文本生成中的标准做法。
