长句会压垮短上下文向量。亲手搭建一个单向量编码器，用长度不断增长的句子测试它，精确地看到信息从何时开始流失——正是这一失败使注意力机制成为必然。

约 10 分钟 深度学习 · Seq2Seq · 注意力机制的动机
前言

行李箱问题

设想你要去度一周假，航空公司限你只能带一件 7 千克的随身行李。你勉强应付得来。现在再设想用同一个行李箱去应付为期六个月的探险。行李箱没变——变的是你的需求。所有装不下的东西都只能留在原地。

2014 年的 Seq2Seq 模型（Sutskever、Vinyals、Le）构建了一个神经翻译器，把整个源句打包进单个固定大小的上下文向量——不妨设其为 512 个浮点数。短句打包得很好，长句则会溢出。本页让你实时运行这一压缩过程，观察翻译质量如何随句子长度增长而崩塌。

读完本页时，你将会看到上下文向量如何挣扎，测量到 BLEU 的下降，并彻底明白为何 Bahdanau 等人一年之后加入了注意力机制。

第 3 步

翻译质量与源句长度的关系

2014 年的论文（Sutskever 等人）按源句长度报告了 BLEU。以下是他们的结果以交互方式重现：BLEU 在超过约 30 个词元后急剧跌落。

Seq2Seq（无注意力） Seq2Seq（反转源句） Bahdanau 注意力（2015）
故事。 反转源句为他们换来了 4-5 个 BLEU 点——并非因为它修复了瓶颈，而是因为它改变了信息流失*发生的位置*（最后读取者 = 最靠近解码器者）。注意力用一个*灵活的查表*取代了固定向量，一举跃过了两条曲线。

模式。 中间的词元最先丢失——它们夹在开头（已褪去）与结尾（最新）之间。这一 U 形曲线正是为何在注意力之前的模型里，束搜索的翻译在长句上以弄错“中间部分”而著称。
第 5 步

注意力 · 移除瓶颈

注意力不是把所有内容硬塞进一个向量，而是让解码器访问编码器的每一个隐藏状态。在每个解码步，它按相关性为它们加权并求平均。

注意力权重 α_t,i
机制。 每个目标步 t 通过从所有源状态 h_1…h_T 中以学得的权重 α_t,i 采样来构建其上下文。长句不再有害——每个源词元都保持可访问。就是这样：注意力化解了瓶颈。
c_t = Σ_i α_{t,i} · h_i     其中    α_{t,i} = softmax(score(s_t, h_i))
常见误解

三种常见的混淆

不实

“把向量做大就行。”
一个 2048 维的向量只是推迟问题，而非解决它。这个瓶颈是结构性的：一个向量要承载来自每一个位置的信息。你终究会耗尽空间。

不实

“反转源句只是一种取巧。”
它是取巧，但是一种务实的取巧，揭示了瓶颈对句子哪一端伤害最大。真正的修复方案（注意力）正是从认识到这一泄露而来。

不实

“现代 LLM 仍在使用编码器-解码器。”
2026 年的大多数 LLM 都是仅解码器结构——它们根本不把源内容编码成向量；整段对话就是一条长序列。编码器-解码器则保留在 T5 等翻译专用模型中。

附加内容

审视同一修复方法的三种视角

模型（年份） 新增内容 50 词元句子上的 BLEU
Seq2Seq（2014）编码器 + 解码器 LSTM，单个上下文向量22
反转 Seq2Seq（2014）翻转源句 · 架构相同26
Bahdanau 注意力（2015）解码器关注所有编码器状态30
Transformer（2017）处处是注意力 · 无循环结构35+
最后总结。 Seq2Seq 瓶颈是注意力机制在教学上的动机来源。此后每一种架构都是“注意力，只是路由方式不同”——Transformer 中的交叉注意力、Stable Diffusion 中的交叉注意力、LLaVA 中的交叉注意力。一旦你体会过瓶颈在何处作痛，修复方案便不言自明。
延伸阅读

从瓶颈到 Transformer 的论文脉络

  • Sutskever, Vinyals, Le (2014) — Sequence to Sequence Learning with Neural Networks. 最初的编码器-解码器模型。
  • Cho 等人 (2014) — Learning Phrase Representations using RNN Encoder–Decoder. 基于 GRU 的同期论文。
  • Bahdanau, Cho, Bengio (2015) — Neural Machine Translation by Jointly Learning to Align and Translate. 第一篇注意力论文——通过让解码器回看修复了瓶颈。
  • Luong, Pham, Manning (2015) — Effective Approaches to Attention-based Neural Machine Translation. 点积注意力，即大多数现代系统所采用的形式。
  • Vaswani 等人 (2017) — Attention Is All You Need. Transformer——彻底放弃了循环结构。
