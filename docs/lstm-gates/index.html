LSTM 门控实验场

一个 LSTM 单元有三道门：遗忘门决定从细胞状态中擦除什么，输入门决定写入什么，输出门决定读出什么。拖动每个滑块，送入一段输入序列，观察细胞状态如何流动 —— 或者冻结不动。

约 8 分钟深度学习 · RNN · LSTM

朴素 RNN 难以处理长程依赖。梯度经过一连串 W⊤·diag(tanh') 连乘之后，要么消失，要么爆炸。Hochreiter 与 Schmidhuber 在 1997 年的洞见在于：让循环拥有自己的状态，并由门控 —— 即 [0, 1] 区间内的 sigmoid 值 —— 来更新该状态，而非通过矩阵乘法。

细胞状态由此成为一条传送带。在每个时间步，遗忘门做乘法，输入门做加法，而只有输出门决定将多少内容暴露为隐藏状态。

实验场

输入在 t=3 与 t=7 处出现尖峰 · 实线 = 细胞状态 c_t · 虚线 = 隐藏状态 h_t

可尝试这些预设

  • 永久记忆 —— f=1, i=0。细胞状态在首个输入之后便冻结。LSTM 正是以这种方式保存长程信息。
  • 始终遗忘 —— f=0。每个时间步都擦除。效果类似于 tanh 饱和的朴素 RNN。
  • 始终覆写 —— f=0, i=1。细胞状态只跟踪最新的输入。
关键方程。 c_t = f_t · c_{t-1} + i_t · c̃_t。遗忘门是一条乘法式路径（不含矩阵乘法），因此经由细胞状态的梯度既不会爆炸也不会消失 —— 它们按 f_t 缩放，而在记忆重要时，网络会学会让 f_t 保持在接近 1 的数值。

LSTM 与 GRU 对比

GRU（Cho，2014）将遗忘门与输入门合并为一个「更新」门，并把 c 与 h 合并。参数更少，精度往往相当。到 2026 年，在二者之间取舍基本属于个人偏好；在大多数任务上二者都被 Transformer 远远超越。但在微型设备与流式场景中，它们仍是主力。

BPTT 与梯度消失的故事

训练 RNN 即沿时间反向传播（BPTT）：将循环展开，视其为权重共享的前馈网络，并沿时间反向传播梯度。朴素 RNN 致命的问题在于：每回退一步，梯度都会乘以同一个循环映射的 Jacobian。若该 Jacobian 的谱半径 < 1，梯度将指数级消失；若 > 1，则会爆炸。

∂L/∂h_0 = ∂L/∂h_T · ∏_{t=1}^{T} ∂h_t/∂h_{t−1}

LSTM 为何能解决这一问题：细胞状态 $c_t$ 通过 $c_t = f_t \odot c_{t-1} + i_t \odot g_t$ 向前传递信息。其 Jacobian $\partial c_t / \partial c_{t-1} = f_t$ 恰恰就是遗忘门的取值 —— 一个位于 $(0,1)$ 区间、可逐步学习的标量。当模型想要记住时，$f_t \approx 1$，梯度便原封不动地回流。这才是 LSTM 能够被训练的真正原因。

窥孔式 / ConvLSTM / xLSTM 变体

  • Peephole LSTM。 各门同时也能看到细胞状态 $c_{t-1}$。在长依赖任务上精度提升有限。
  • GRU。 少一道门；少一个状态；在多数任务上表现相当；成本更低。
  • ConvLSTM。 以卷积替代矩阵乘法；适用于时空数据（雷达、视频、卫星时间序列）。
  • xLSTM（2024）。 更新后的门控 + 矩阵值记忆；可进一步扩展；在语言建模上与小型 Mamba 不相上下。

2026 年何时该选用 LSTM

  • 状态空间承载逐步都至关重要的流式推理（低延迟语音、边缘端时间序列预测）。
  • Transformer 的 KV cache 过于昂贵的微型嵌入式设备。
  • 在长时段时间序列上转向 Mamba 或 PatchTST 之前，作为基线。

除此之外，现代 Transformer 与 SSM 占据主导。LSTM 之所以沿用至今，是因为它是讲解梯度消失问题最清晰的教学模型，也是「记忆」被显式表达为门控状态的最简模型。
