交互式讲解

数据增强与 Mixup

二十四个点算不上充裕的训练集，分类器会在它们之间的空白处画出一条紧张而参差不齐的边界。有两种廉价的技巧可以从现有数据中制造更多数据：数据增强在每个点周围散布貌似合理的邻居点，mixup则沿点之间的连线上放置软标签点。分别开启这两者，观察边界如何松弛为一条宽阔而自信的间隔带。

约 9 分钟 深度学习 · 泛化 · 正则化
前言

两种凭空制造训练数据的方式

模型只能看到你提供给它的训练点；在其他任何地方，它都只能靠猜测。数据增强与 mixup 都通过合成新的带标签样本来应对这种空白 — 但它们填充的是不同的几何结构。

  • 数据增强对每个样本施加保持标签不变的扰动 — 抖动、小幅旋转或缩放。一张猫的照片平移两个像素后仍然是猫，于是我们得到一个携带相同硬标签的新点 $\tilde{x} = x_i + \varepsilon$。这就在每个训练点周围鼓起一小片点云。
  • Mixup 将两个样本及其标签线性混合：
$$\tilde{x} = \lambda\,x_i + (1-\lambda)\,x_j, \qquad \tilde{y} = \lambda\,y_i + (1-\lambda)\,y_j, \qquad \lambda \in [0,1].$$

位于一个蓝色样本与一个橙色样本正中间的点，其标签为「一半蓝、一半橙」。mixup 不像前一方法那样在点周围铺开点云，而是沿样本之间的线段铺设一条软标签点的连续谱，从而教模型在从一个类别过渡到另一个类别时线性而平缓地改变其预测。

收获

同一目标，不同几何

两种方法都是数据空间上的正则化手段：它们不触及损失函数或权重，而是扩大模型需要负责的输入空间区域。但它们扩大区域的方式不同，而这一差异正是全部要点所在。

  • 数据增强在点周围长出球状区域。 它把你本就相信的一种不变性（「小幅抖动不改变类别」）编码进去，从而加厚每个类别的支撑，并剥夺模型过拟合到某个像素级完美样本的自由。
  • Mixup 在点之间长出线段。 通过要求 $f\big(\lambda x_i + (1-\lambda)x_j\big) \approx \lambda y_i + (1-\lambda)y_j$，它迫使预测在样本之间线性变化。这种线性斜坡构成一个宽阔且经过校准的间隔 — 并且抑制了普通训练所偏爱的那种极度过度自信的外推。
  • 二者都缩小模型所见与将要被测试之间的差距 — 与权重衰减或 dropout 具有相同的泛化目标，只是通过修改数据而非模型来达成。
在实践中。 数据增强与领域强相关，且几乎是免费的午餐： 图像用翻转、裁剪、色彩抖动；音频用时间扭曲；文本用词元丢弃。 Mixup 则与领域无关 — 只需几行代码将一批数据与其自身的打乱副本混合 — 并且还兼具校准与抗标签噪声的作用。二者叠加使用效果更佳。
