交互式讲解

移位窗口（Swin）

完全自注意力会将每个 patch 与其余每个 patch 两两比较 —— 开销随 patch 数量的平方增长。Swin 则仅在 小窗口内部做注意力，成本低廉且呈线性。使它不会在窗口接缝处失明的诀窍是：在相间的层上，将窗口网格移位半个窗口， 从而使原本位于边界两侧的 patch 现在并置在一起。点击任意 patch，即可看清它究竟能与谁「交谈」。

约 8 分钟 深度学习 · 视觉 Transformer · 注意力机制
前言

为何不干脆对所有位置都做注意力？

视觉 Transformer 将图像切成 $N \times N$ 的 patch 网格，得到 $N^2$ 个词元。全局自注意力要构成所有两两配对，因此其开销按 $(N^2)^2 = N^4$ 增长 —— 相对于词元数呈二次增长。分辨率翻倍，注意力开销便上升十六倍。这在 高分辨率图像上难以为继。

Swin 的对策是把注意力限制在互不重叠的 $M \times M$ patch 窗口之内。每个窗口只在其自身内部做完全注意力， 忽略窗口之外的一切。在窗口尺寸 $M$ 固定时，总开销为

$$\underbrace{\left(\tfrac{N}{M}\right)^{2}}_{\text{\# windows}} \times \underbrace{(M^{2})^{2}}_{\text{pairs per window}} \;=\; N^{2} M^{2},$$

这相对于词元数 $N^2$ 是线性的。代价显而易见：patch 永远无法关注其窗口之外的任何内容，信息无法跨越接缝。下一节将给出补救办法。

实验环节

窗口，以及缝合它们的移位

下图为划分为若干注意力窗口的 patch 网格（以粗线标出接缝）。点击任意 patch 将其选中：它所能关注的 patch —— 恰好是其所在窗口 —— 会亮起，其余则变暗。现在拨动 Shift 开关。整个窗口网格平移半个窗口， 于是所选 patch 落入一个拥有新邻居的新窗口。将未移位层与移位层叠加起来，经过两层之后，一个 patch 便能向各个方向跨越边界。

收益

先移位，再移回：感受野的增长

单一窗口层视野狭窄 —— 一个 patch 只能看见其 $M \times M$ 的邻域。但 Swin 交替进行：第 $L$ 层使用普通划分， 第 $L{+}1$ 层使用移位后的划分（位移 $\lfloor M/2 \rfloor$）。靠近接缝的 patch 在第 $L$ 层关注一组 patch， 随后在第 $L{+}1$ 层关注另一组不同且与之重叠的 patch。两层复合之后，信息便能向各个方向跨越边界流动 —— 而无需构成任何单一的全局注意力矩阵。

  • 低成本。 每一层都保持 $O(N^2 M^2)$：相对于词元数呈线性，绝不会达到 $N^4$。
  • 连通。 移位窗口与未移位窗口交替出现，把接缝缝合起来，于是有效感受野逐层增长，直至覆盖整幅图像。
  • 层次化。 Swin 还在各阶段之间合并 patch，使网格缩小、每个词元所概括的范围扩大 —— 正是这种金字塔结构，使它能够直接充当检测与分割任务的主干网络。
真实实现。 Swin 并不在边缘处构建参差不齐的窗口，而是对整个特征图做一次循环移位， 运行普通的等尺寸窗口注意力，并使用一个注意力掩码，使从对侧边缘绕回的那些 patch 实际上不会相互关注。上图绘制的是如实呈现的划分； 而这一技巧不过是让同一批邻居集合在 GPU 上高效实现的方式。
