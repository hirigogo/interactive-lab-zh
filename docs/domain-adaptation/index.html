视觉中的域偏移：深入剖析

一次完整的视觉导向之旅：一份你实际会遇到的偏移分类法，十种端到端详加演练的技术（BN 统计量、CORAL、MMD、DANN、AdaBN、MixStyle、TENT、无源域自适应、FrePolad 风格归一化、提示微调式域自适应），一棵用于选择的决策树，以及一个保持直觉可靠的实时二维演示。

约 30 分钟 分布偏移 · 视觉 · 自适应
前言

差距从何而来

测试集上的准确率为 92%。生产环境中的准确率却是 67%。为什么？在每一篇论文里，这都称为「域偏移」或「分布偏移」，但这些说法掩盖了六个截然不同的问题。你必须先弄清自己面对的是哪一种，才可能修复它。

第 1 步

二维试验场（实时）

让目标域相对于源域发生漂移；观察仅在源域上训练的分类器在目标域上崩塌。勾选 CORAL 进行特征对齐；观察大部分差距被弥合。能量热力图与 OOD ROC 展示你能以多高的置信度标记出真正的 OOD 点。

第 2 步

十种视觉专用的自适应技术，逐一详述

以下是对文献中常见技术的实用总结，以及如何在视觉流程中真正使用每一种。顺序：由廉价到昂贵。

2.1 BatchNorm 统计量自适应（AdaBN）

书中最廉价的修复手段。取你已训练的模型；用数百张无标签的目标域图像重新计算每个 BatchNorm 层的滑动均值 / 方差；冻结仿射参数 $\gamma, \beta$。30 秒即可完成，无需反向传播。当偏移主要处于低层（光照、传感器噪声）时，往往能弥合 30-60% 的差距。

注意事项。若偏移是语义层面的（新物体、新类别），它无济于事。对纯 LayerNorm / GroupNorm 模型也无济于事——这些模型没有可重新拟合的滑动统计量。对 ViT 而言，其对应做法是「在一批留出的目标域数据上重新校准 LayerNorm 的仿射参数」。

2.2 CORAL——二阶矩匹配

用 $C_S^{-1/2}$ 对源域特征白化，再用 $C_T^{1/2}$ 重新着色，在匹配后的源域数据上训练头部。上方的实时演示正是如此。对于表格数据与特征层面的对齐而言是强基线；在原始像素上效果较弱。

2.3 MMD——核最大均值差异

增加一个损失项，将源域特征的核均值推向目标域特征的核均值。在 DAN（Long 等，2015）与 DDC 中以 MK-MMD 惩罚项实现。当你想对齐超出二阶统计量的分布时颇为有用。

2.4 DANN——域对抗训练

增加一个小型域分类器头部，试图区分源域与目标域。通过梯度反转训练特征提取器来欺骗它（Ganin 与 Lempitsky，2015）。特征变得域不变，而下游任务头部依然有效。此后每一种对抗式域自适应方法（CDAN、MDD、ADDA）都是对 DANN 的细化。

实现提示。梯度反转层在前向传播中就是恒等映射，在反向传播中则是符号翻转的乘子 $-\lambda$。在训练过程中将 $\lambda$ 从 0 调度到 1；否则对抗信号在早期过强，会破坏任务头部。

2.5 MixStyle——增广域的风格混合

在网络内部，混合来自不同（或随机）源域的两个样本的逐通道均值与标准差（Zhou 等，2021）。这是一种模拟未见风格的廉价数据增广。对跨相机与跨光照偏移颇为有效。

2.6 IRM 与 group-DRO——稳健 ERM

当你有多个已标注的源域时，不变风险最小化（Arjovsky 等，2019）与群组分布稳健优化（Sagawa 等，2020）训练模型在最差环境而非平均意义上表现良好。当测试域「未见但相关」时颇为有用。

2.7 测试时自适应——TENT 与 SHOT

在部署时进行自适应，且无需源域数据。TENT（Wang 等，2021）通过最小化测试批次上的预测熵来更新 BatchNorm 的仿射参数。SHOT（Liang 等，2020）更进一步：无源域自适应，你只需交付在源域上训练的模型，然后在目标域上以自训练伪标签来适配特征。二者都适用于小型流式批次；若批次类别不平衡或包含过多 OOD，二者都可能失效——熵最小化会坍缩到单一类别。

2.8 伪标签与自训练

半监督域自适应的主力方法。用源域模型在置信度高的目标域样本上生成标签，再在（源域已标注 ∪ 目标域伪标签）上重新训练模型。如此迭代。与一致性正则化（FixMatch、MixMatch）结合可获得更强的效果。

2.9 大型骨干网络上的提示 / 适配器 / LoRA 式域自适应

对于大型预训练骨干网络（CLIP、DINOv2、SAM），一个极小的域特定提示或 LoRA 适配器往往能以完整域自适应训练所需参数的零头弥合差距。Visual Prompt Tuning、CoOp / CoCoOp、AdapterHub。当源域数据属于隐私或不可获取时尤为有吸引力。

2.10 基于扩散的域转换

当源域与目标域在视觉上存在差异时（仿真到真实、雨天 → 晴天、季节变化），训练一个条件扩散模型，在推理之前将目标域图像转换为带有源域风格的图像（或反之）。CycleGAN 是 GAN 时代版本；如今 ControlNet / IP-Adapter / SDXL-Turbo 转换构成了实用的技术栈。

第 3 步

决策树——30 秒内选出技术

  1. 问题 1：你有已标注的目标域数据吗？若有任何已标注的目标域数据 → 在目标域上微调头部 + LoRA；你不需要域自适应。结束。
  2. 问题 2：仅有未标注的目标域数据，能重新训练吗？先试 AdaBN（无需代价）。若模型使用 BatchNorm 且偏移属于光照 / 传感器 / 天气类型，这往往能弥合大部分差距。若不够，则在特征上加入 CORAL 或 MMD。若仍不够，则训练 DANN。
  3. 问题 3：训练时没有目标域数据，仅在测试时才有？测试时自适应：BN 模型用 TENT；无源域用 SHOT；否则依赖稳健训练的骨干网络（DINOv2 特征 + 小型头部）。
  4. 问题 4：有多个已标注的源域，但没有目标域？域泛化：IRM / group-DRO / MixStyle 增广。或者在所有源域上预训练并依赖正则化。
  5. 问题 5：视觉差距巨大（仿真 → 真实、白天 → 夜晚）？基于扩散的域转换；或激进的风格增广；或二者兼施。
  6. 问题 6：隐私限制 / 无法访问源域？无源域自适应（SHOT、AdaContrast）；只交付模型，并在目标域上以伪标签 + 熵最小化进行自适应。
2026 年视觉领域的默认配方。(1) DINOv2 骨干网络。(2) 在源域上训练线性 / LoRA 头部。(3) 若架构中含 BN 则用 AdaBN（ViT 通常不含）。(4) 测试时用 TENT。(5) 用保形预测包裹预测以获得有保证的覆盖率。这套组合能处理你会遇到的大部分偏移；只有当骨干网络很小或差距巨大时，才诉诸 DANN / CORAL / MMD。
第 4 步

OOD 检测——知道何时不该预测

当源域与目标域有重叠时，自适应能弥合差距。真正分布外的输入则需要一个独立的检测器以及一条拒绝预测的路径。有五种值得了解的检测器：

  • 最大 softmax 概率（MSP）。最廉价，在大规模场景下出人意料地难以超越。对 $\max_c p(c\mid x)$ 设阈值。
  • 能量分数（见上）。相较 MSP 有严格提升；计算量相同。2024 年以来的默认选择。
  • 倒数第二层特征上的马氏距离。在训练特征上为每个类别拟合一个高斯分布；以最小类马氏距离为新的输入打分。当骨干网络给出的簇较为干净时效果良好。
  • ViM、KNN-OOD。以虚拟 logit 或 k-NN 距离与倒数第二层的特征库进行匹配。在大型视觉基准（OpenOOD）上表现强劲。
  • 离群样本暴露。在训练期间加入一个极小的、由「明显 OOD」图像构成的数据集，并以均匀分布作为目标；模型便学会在分布外保持不确定。廉价而可靠。
第 5 步

实例演练——面向目标检测器的仿真到真实迁移

针对一种常见视觉域自适应设置的具体流程：在仿真中训练目标检测器，部署到真实照片上。这是机器人 / 自动驾驶 / 农业科技中的标准配方。

  1. 在真实照片上预训练骨干网络（无需代价）。DINOv2 或带 CLIP 风格的骨干网络。不要在仿真数据上从零训练——你会把仿真的观感烙进模型。
  2. 在仿真数据上训练检测器（已标注）。标准的 DETR / RT-DETR / YOLOv10 头部；前 5 个 epoch 冻结骨干网络以避免破坏特征。
  3. 加入激进的风格增广。在特征空间使用 MixStyle + 色彩抖动 + 对仿真器输出施加 RandAugment。仿真器的天气多样性也有帮助。
  4. 域转换前置步骤（可选）。训练期间对每个批次运行仿真到真实的 CycleGAN / ControlNet 转换。可大幅缩小视觉差距，代价是每批次计算量增加。
  5. 真实数据微调（若有任何已标注的真实数据）。即便只有 100 张已标注的真实图像 + 现有的 10 万张仿真图像，以低 10 倍的学习率端到端微调，也能大幅胜过仅用仿真数据。
  6. 测试时自适应。在检测头部上使用 TENT + 一个小型的自伪标签 EMA 循环。
  7. OOD 门控。一个能量分数阈值：若图像块的能量低于阈值则不输出边界框。始终包裹已部署的检测器。
  8. 保形校准。对检测器的置信度做保形化，使「0.85」真正意味着 85% 的精确率；参见保形预测一文。
第 6 步

实例演练——多站点医疗 / 卫星场景中的偏移

当「域」是站点（医院、传感器站点、卫星过境）时，问题在于域泛化，而非单目标域自适应。配方如下：

  1. 留一站点交叉验证。务必如此。随机划分会因站点而泄漏，并将泛化能力高估 10-30 个百分点。
  2. 训练期间按站点分层采样。每个站点等权，而非每张图像等权。可防止任何单一站点主导梯度。
  3. Group-DRO 损失。针对最差站点的损失进行优化。平均准确率略有下降，最坏情况则取胜。
  4. 仅在训练时而非测试时引入站点条件。训练期间将站点编码为嵌入并输入骨干网络；测试时将其丢弃，依靠泛化。有助于将站点效应与类别效应解耦。
  5. 按站点建立层次贝叶斯模型。参见部分池化一节；每个站点有自己的后验，并被拉向全局先验。当每站点数据量较小时尤为相关。
  6. 按站点建立 OOD 检测器。训练一个 OOD 检测器，标记出与任何已见站点都不相似的输入。
第 7 步

陷阱与误区

  • 「BatchNorm 在 eval 模式下对目标域没问题。」并非如此。eval 模式将滑动均值 / 方差锁定为源域的取值；TENT / AdaBN 之所以存在，恰恰是因为这样做会损失精度。
  • 「DANN 已收敛」但准确率很差。对抗式域自适应可能找到这样的解：域不变特征同时也是类别不变的。务必以目标域准确率评估，而非对抗损失。
  • 开发期间随机预览目标域。在模型选择时偷看目标域很诱人；这会使你的超参数选择偏向测试集。当你没有目标域标签时，应使用无监督的选择标准（例如目标域上的自置信度）。
  • 「我的模型加上增广后反而更差。」风格增广与天气增广只对它们所模拟的偏移有帮助。若你的偏移是传感器波段重排或频谱层面的，RGB 增广便无能为力。
  • OOD 检测器选错了分数。在多数基准上 Energy > MSP > 马氏距离，但 OpenOOD 表明正确的选择取决于骨干网络与偏移类型。三者都测一测；在合成的 OOD 集上按 AUROC 择优。
  • 仿真过拟合。仅在仿真数据上训练的检测器学会的是识别仿真器的渲染器。真实世界部署便会失败。域随机化或仿真到真实转换不可妥协。
  • 频谱 / 多模态偏移。当目标域是多光谱时，在 RGB 上做 CORAL 无济于事。应改为在对地观测基础模型上预训练，并在特征层面进行自适应。
最终结论。视觉中域偏移的难点很少在于选择损失函数——而在于诊断你面对的是哪一种偏移，并据此匹配相应技术。第 3 步中的决策树，加上第 6 步中诚实的留一站点评估，将为你省下一年的调试时间。
