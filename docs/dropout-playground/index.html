Dropout 演练场

滑动丢弃概率 $p$，观察一个小型网络闪烁变化。每一次 前向传播都会随机让不同的隐藏单元子集沉默，因此每一次 传播都是不同的子网络。经过多次传播，你实际上是在训练一个 共享权重的指数级集成 — 这正是 2012 年那项最具影响力的 正则化方法背后的核心直觉。

约 8 分钟阅读 深度学习 · 正则化
核心思想

随机使神经元沉默

Dropout 是 Hinton 于 2012 年提出的技巧：在每一次训练时的前向传播中， 随机将一部分隐藏激活置零。一个单元以 保留概率 $1-p$ 存活，并以概率 $p$ 被丢弃。将每个单元的开关记为 Bernoulli 变量 $m_i$，将丢弃后的激活记为 $\tilde h_i$：

$$\tilde h_i = \frac{m_i}{\,1-p\,}\; h_i, \qquad m_i \sim \mathrm{Bernoulli}(1-p).$$

同时发生了两件事。掩码 $m_i$ 将随机的单元子集置零。 因子 $\tfrac{1}{1-p}$ 对存活单元重新缩放，使该层的 期望 输出保持不变 — 这就是 PyTorch 及所有现代框架 采用的“反向 dropout”约定，也正是测试阶段能够直接使用 恒等映射的原因。请在下方体验这两种效应。

演练区

每次前向传播使用一个掩码

一个小型 MLP：四个输入、十个隐藏单元、一个输出。隐藏层 激活 $h_i$ 固定不变（此处权重不改变）— 只有 dropout 掩码被重新采样。在 train 模式下，每个存活单元 被缩放 $\tfrac{1}{1-p}$ 倍；被丢弃的单元及其连接边变灰。在 eval 模式下 dropout 关闭：所有单元都激活，不做任何缩放。

回报

为何要按 1/(1−p) 缩放？

若不进行缩放，一个在训练时仅保留 $1-p$ 比例单元的层， 其激活强度会远弱于测试时的完整层 — 下一层所看到的 分布将无法匹配。反向 dropout 从构造上解决了这一问题。 由于 $\mathbb{E}[m_i] = 1-p$，

$$\mathbb{E}[\tilde h_i] \;=\; \frac{h_i}{1-p}\,\mathbb{E}[m_i] \;=\; \frac{h_i}{1-p}\,(1-p) \;=\; h_i,$$

因此期望激活保持不变，进而期望输出 恰好等于确定性的评估输出：

$$\mathbb{E}\!\left[\sum_i v_i\,\tilde h_i\right] \;=\; \sum_i v_i\,\mathbb{E}[\tilde h_i] \;=\; \sum_i v_i\,h_i \;=\; y^{*}.$$

上述橙色滑动均值曲线正展示了这一等式。你所付出的 代价是方差 — 单次带掩码的传播只是对 $y^{*}$ 的带噪估计， 且随着 $p \to 1$ 噪声急剧增大：

$$\mathrm{Var}[\tilde h_i] \;=\; h_i^{2}\,\frac{p}{1-p}.$$
常见错误。 推理时忘记调用 model.eval() 会使得 dropout 保持开启：预测结果在多次运行之间闪烁， 概率校准也随之失效。与之镜像的错误是调用了 model.train() 却从不将梯度清零 — 失效方式不同，却有着相同 “我的模型为何随机？”的症状。
两种直觉

为何使神经元沉默可以正则化

集成视角

一个含 $N$ 个单元的隐藏层有 $2^{N}$ 种可能的开 / 关掩码。每个迷你批次 训练一个随机抽出的稀疏网络，但它们全都 共享同一组 权重。在整个训练过程中，你实质上是仅付出单个模型的代价， 就拟合了一个指数级规模的集成。在测试时，你去掉掩码并使用 完整网络，它近似于整个集成的几何平均预测 — 免费获得了集成效果。

共适应视角

若无 dropout，单元 $j$ 可能学会依赖单元 $k$ 始终存在 — 这是一种拟合训练噪声的脆弱共谋。由于任何同伴 都可能在下次传播中消失，dropout 迫使每个单元自身便有用， 并将表示分散到众多单元之中，而非集中在少数脆弱的单元上。 其结果是一个更平滑、泛化更好的函数。

实践应用

2026 年 dropout 的适用位置

  • Transformer — 在注意力与 FFN 之后取 p = 0.1。在多数训练方案中仍是默认做法。
  • 现代 CNN — 通常取 0。正则化的任务由 BatchNorm 加上大量数据增强来承担。
  • LoRA 微调 — 通常取 0 或 0.05。适配数据稀缺，过度正则化会造成损害。
  • 经典 MLP — 在各隐藏层之间取 p = 0.5。这是 2012 年的原始设定，也是上方演练场所采用的设定。

值得了解的变体

  • SpatialDropout / DropBlock。 在 CNN 中丢弃单个像素收效甚微，因为相邻像素彼此相关。 SpatialDropout 丢弃整个特征图；DropBlock（Ghiasi 等人，2018）丢弃连续的方形区域 — 对于卷积网络而言，二者都远比朴素 dropout 更强。
  • DropPath / 随机深度（Huang 等人，2016）。随机丢弃 整个残差模块。在极深的 ResNet、EfficientNet 与现代 ViT 中是标准做法；它相当于在网络深度维度上做集成。
  • DropConnect（Wan 等人，2013）。丢弃单个权重而非激活。每个迷你批次的方差更大；由于朴素 dropout 更廉价，实践中很少使用。
  • 变分 / MC dropout（Gal & Ghahramani，2016）。在各时间步之间复用同一掩码，或 在推理时保持 dropout 开启，以采样一个近似后验来刻画不确定性。

MC dropout — 用 dropout 刻画不确定性

Gal & Ghahramani（2016）表明，在推理时保持 dropout 开启 可将一个确定性网络变为近似的贝叶斯网络：每次带掩码的传播都是 来自某个后验的一次采样。运行 $K$ 次前向传播，预测结果的散布 便是一种廉价的不确定性估计 — 正是上方的蓝色点散， 此时应将其理解为后验，而非需要平均消去的噪声。

它廉价且简便，但 MC-dropout 给出的不确定性通常偏向欠自信， 且很少能胜过深度集成。可将其视为一个基线；当校准至关重要时， 应选用集成方法，并将二者之一与 温度缩放 或 保形预测 配合使用，以获得 真正可据以行动的可信度。
